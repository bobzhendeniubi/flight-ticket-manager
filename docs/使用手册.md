## 一、我是顾客 —— 怎么订（在"下单台"）

**第 1 步｜进去**：点群里的链接。
**第 2 步｜搜产品**：首页是机票；想订别的，点顶部的 **酒店 / 接送 / 签证 / 岘港全包套票**（岘港是越南的海滨度假城市）。选日期、人数、房间。
**第 3 步｜加入购物车**：选好点"加入购物车"。可以多加几样，结账时**只勾你要买的**，没勾的留在车里。
**第 4 步｜填出行人（坐飞机的人）**：
  - 最快：**拍护照**，姓名 / 护照号 / 出生日期自动填好（偶尔慢或认错，手动改一下就行）。
  - 也可以一个字一个字手填。人数不够系统会自动补空位，不会卡住。
**第 5 步｜确认下单**：核对明细 → 下单。价格按当天算，**以你下单那一刻看到的为准**。

**💰 怎么付钱？**
公测期**系统里那个"支付"按钮，点了也没事**——不会真扣钱、也不会把订单搞乱（这是测试）。真正的钱**按老办法**：转给我们 / 你的代理，我们收到后在处理台帮你标"已付"。所以你放心把单下完就行。

**↩️ 能退吗？** 能，按产品各自的退改规则。要退**直接找你的代理或客服**。

**❓ 出问题找谁？** 〔待补：客服微信 / 电话〕

> 手机微信里也有小程序，操作一样：搜机票 → 加购物车 → 下单 → 看订单。

## 二、我是代理 —— 帮客户下单 + 看佣金

代理 = 顾客能做的全部，**再加**下面这些。

### A｜给一个客户下单
和上面"我是顾客"完全一样，在**下单台**做。

### B｜给一批客户一次性建单（你最常用）
在**处理台**找到 **"批量创单"**：
**第 1 步**：选航班 / 产品、舱位、出行日期。
**第 2 步**：填联系人、电话。
**第 3 步｜录乘客**：可以**一次粘贴一串姓名，一行一个人**，例如：

```
张三
李四
王五
```

  粘进去后，系统给**每个人各生成一张单**。
**第 4 步**：确认 → 一次性建好多张单。
**第 5 步｜补护照信息**：建好单后，进**每张订单的乘客详情**，逐个补护照号 / 出生日期（也可以让客户拍护照自动填）。

> 〔截图：批量创单页的"粘贴姓名"输入框〕

### C｜看我的佣金 / 分成
在**下单台**点 **"我的分成"**，看你的佣金对账。〔截图〕

### D｜管我的下级
在**下单台**点 **"我的团队"** 看下级；在**处理台**能管理下级和他们的订单。

> ✅ 说明："看不到成本和财务"指的是**看不到公司的进货价和整体财务报表**；**你自己的佣金 / 分成是能看到的**——不是让你白干，放心。

## 三、我是操作 —— 一单从接到出票怎么走（全在"处理台"）

下面是**从头到尾一条线**，照着做。

**第 1 步｜找单**：进 **"订单管理"**，用 **"按出行日期筛选"** 挑出本周要走的单。〔截图：筛选框在哪〕

**第 2 步｜接单（认领）**：在单子上点 **"认领 / 我接了"**。
  - 👉 点了会怎样：这单记成 **"你在处理"**，别人能看到，避免两人重复做同一单。
  - 👉 想转给别人：让对方在这单上**再点一次"认领"**，就归 ta 了（系统只认最后认领的人）。点错不要紧，不会动到订单本身。

**第 3 步｜按进度改状态**：常见顺序——
  **待付款 →（收到钱）已付 → 处理中 → 已出票 → 完成**。
  - 👉 改错了：管理员能强制改回来，每次改谁改的都有记录。

**第 4 步｜确认收款**：线下收到钱后，在订单上点 **"确认收款"**，填金额并**上传收款截图**。
  - 👉 点了会怎样：记一笔收款，金额**累加**（可以分次收；不填金额就默认按"还差多少"收；收满自动转"已付"）。系统**不会让你收超过应收**，多填会被拦下。
  - 👉 标错 / 传错了怎么办：**没有"撤销"按钮**，所以别重复乱点；把情况发给**管理员**处理（每一笔收款都有记录可查）。

**第 5 步｜准备出票**：
  - 先确认每个人**护照齐了**：可点 **"一键打包下载护照图片"** 整单下载。
  - 点 **"一键导出 PNR Excel"** → 下载一个 Excel，**就是交给航司的格式**，直接发航司。
  - 👉 导出内容不对：回系统把乘客信息改对，再重新导一次。

**第 6 步（套票）｜拼房**：套票订单可 **"自动拼房"**（按星级 / 性别 / 备注分房）。

### 你会在订单上看到的几个"状态"，分别啥意思
- **出票状态**：去程 / 回程的票出了没。⚠️ 公测期"出票成功"**不是真出票**（还没接航司），只是改个状态给你看。
- **开票状态**：**发票**开了没（未开 / 客户已要求 / 已开）。**注意：是发票，跟"出票"是两回事！**
- **签证状态**：签证办到哪步了（系统自动显示，不用你手动维护）。

### 还有两个常用的地方
- **座位统计**：余位**不足 20 会自动标红**，提醒快满了。
- **操作部待办 / 特殊提醒**：需要人工跟进的事都列在这里。

## 四、我是财务 / 老板 —— 录成本、看毛利、导对账

**只有管理员账号能看财务**（别人看不到；谁看了都会留记录）。全在**处理台**。
> 💰 **所有金额统一人民币**——没有汇率/外币换算这回事，填一份数就行，省心。

### 第 1 步｜先把成本录进去（不录，毛利就不准）
1. **产品成本**（"财务 → 成本维护"）：酒店净房价、签证成本、接送结算价——**都填人民币**。
2. **航班成本**（"航班管理" → 按班次填）：
   - **包机总成本**（CNY）—— 整班次付给航司的钱。
   - **机场税(去程, CNY)** + **机场税(回程, CNY)** —— 每位乘客的机场税。
   - 👉 两项**分开填**。系统按"**包机总成本 ÷ 总座位**"算每位乘客分摊的机票成本。

### 第 2 步｜看毛利看板（可选时间段）
- **概览**：收入、成本、**毛利**、净利，按产品类别拆开。
- 名词用大白话解释：
  - **毛利 = 收入 − 成本**。
  - **净利 = 毛利 − "空座沉没成本"**。
  - **空座沉没成本** = 包机**没坐满时，空着的那些座位的钱也是你的成本**；系统帮你把这块也减掉，让净利更接近真实赚多少。
- **航班毛利**：每班坐了几成、收入、包机成本、空座亏多少、净利。
- **订单毛利**：每一单的收入 / 成本 / 毛利率。
- **月度趋势**：每月收入 / 成本 / 毛利的走势。

### 第 3 步｜导出对账表
- 点 **"导出"**，下载一个 **Excel 表（.xlsx，用 Excel 或 WPS 直接打开）**。
- 内容是**一行一位乘客**的明细，**全部人民币**：机票成本（包机分摊）、机场税、房费、签证、车费、客单/整单毛利。
- 〔待补：附一张**导出样表截图**，标明每列含义，方便你对照现有模板看口径对不对〕

> ⚠️ 公测期里的成本数字是**估算的演示值**（比如机票按 70% 估）。**请先按真实数字改了，再看毛利对不对。**
> 💡 **口径变化提醒**：导出表里的"机票成本"现在按**包机分摊**算（包机总成本 ÷ 总座位 × 乘客数），不再是"单票成本×汇率"——和你以前 Excel 的数字可能有差，是预期的，跟"航班毛利"页一致。

## 五、几条要记住的规则

- **护照有效期**：离出发日**不足 90 天 → 不能下单**；**不足 6 个月 → 每人加收 200**（临期附加费）。
- **价格实时算**：以**下单那一刻**看到的价格为准。
- **不会卖超**：同一个座位不会被两个人同时买走。
- **付款是线下收**：公测期系统不真扣钱，钱按老办法收，处理台标"已付"。
