2. **实测**：同样先 `git pull` 再 `infra/deploy.sh prod` → 立刻装附件备份 crontab 与看门狗 `.watchdog.env`（要推送地址）→ 查磁盘余量 → 回填 dry-run → 分批 apply → 低峰 VACUUM FULL → 低峰重建 postgres 生效慢查询统计。
