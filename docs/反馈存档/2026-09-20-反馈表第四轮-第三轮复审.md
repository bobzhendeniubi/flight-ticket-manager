### a. N1 重开

- **查重顺序**：`reminders.rules.ts:1494` reconcile（含重开）→ `:1496` 空候选早退 → `:1499-1503` `existing` 查 `ruleKey in unique`（不带 status）→ `fresh = unique − existingKeys` → createMany(skipDuplicates)。重开成功：行变 OPEN，仍被 existing 认出 → 不建；重开写回 0 行（反例 A3 强制 count=0）：行仍 DONE，同样被 existing 认出 → 不建、不漏（下一轮再试）。**不会重复建也不会漏建**。反过来先查重后重开会白跑一轮，但也不会错——注释 `:1489-1493` 说法准确。
