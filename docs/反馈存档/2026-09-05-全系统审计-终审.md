# 全系统审计 · 终审报告（2026-09-05）

基线：main @ab2bddd（双栈已部署）。17 路 sonnet 代理只读审计（业务口径 6 路 / 代码 bug 8 路 / 前端 3 路），每条带 `文件:行号` 证据；终审逐条复核了 HIGH 以上及有争议的条目，复核结论以本文为准（分路原始报告见附录）。已知未修与已拍板事项（假票号开关、余额回补死路、毛利率恒 100%、拆单不重算佣金、随机档需求池等）按去重清单剔除，只保留**新发现**或**已知问题的新扩面**。

## 总评

- 资金内核（认款/撤销/超收/退款/预存款）经多轮审计后很扎实，这轮没有新的丢钱级 bug；**新问题集中在边界口径不统一、售后通道之间的一致性、以及三条对外暴露的口子**。
- 三条能被外人直接打到的：代理改客户归属（越权）、匿名 AI 接口被顶替系统提示词、待支付单无限刷「已验证」评价。
- 两条会让运营当场卡死的：改签申请中的单不能取消、星级不符换酒店没有放行原因入口。
- 一条品牌铁律：AI 客服在前台自称「世途旅行」。
- 两条后台会静默弄坏数据的：酒店房型改名把挂它的套餐/历史订单房型引用置空；占位单认款双击记两次。
- 小程序整体未跟上（品牌、开发登录、支付路径），发版前必须清一遍。

## 四、需要拍板的口径（不是纯 bug，改之前先定）

1. **代理算不算「内部录单」**（B-1）：现在支付超时口径把代理当内部（永不退位），酒店超售口径三处注释打架。定一条，三处对齐。
2. **结算价锁锁什么**（B-6）：只锁结算价本身，还是锁一切改应收的动作（改期费/升舱/换店/加项/单房差）。
3. **收款复核锁拦不拦余额抵扣**（B-7）：多付转余额、余额抵扣、转挂账池目前不受锁。
4. **动钱要不要财务岗**（B-8）：认款/撤销/转移/流水导入现在任意 STAFF 可做，只有看报表限财务岗。
5. **单房差抬房要不要过余量闸**（B-10）：0717 拍板靠提醒兜底，之后其它路径都加了闸，只剩它一处。
6. **月结单 GMV 与佣金取哪个时点**（B-9）。
