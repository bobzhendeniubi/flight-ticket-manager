## 二、重点测这条主线

**① 先录成本**（财务 → 「成本维护」标签页）
- **汇率**：USD→CNY、VND→CNY（机票、机场税可设不同汇率）
- **产品成本**：酒店净房价（CNY 或 VND）、签证成本（CNY 或 USD）、接送结算价
- **航班成本**：到「航班管理」页，按班次填**包机总成本 / 单票成本(USD) / 机场税(USD)**

**② 看财务看板**（财务 → 各标签页，可选时间区间）
- **概览**：累计收入 / 成本 / **毛利** / 净利（净利已扣"空座沉没成本"），按品类拆分
- **航班毛利**：每班次载客率、收入、包机成本、**空座沉没**、净利
- **订单毛利**：每单收入 / 成本 / 毛利率
- **月度趋势**：收入/成本/毛利的月度走势

**③ 导出对账表**
- 右上角「**导出 xlsx**」→ 一行一位乘客的《财务核对收入明细》（含 USD/VND/CNY 成本拆分 + 机场税 + 客单/整单毛利）
- 对照你现在 Excel 的口径，看**哪些列对不上、少了什么列、算法哪里和你不一样**

> 重点反馈：**毛利/成本算得对不对？口径和你现在的表一致吗？导出的 xlsx 能不能直接用？**
