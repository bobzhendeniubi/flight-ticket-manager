## 二、重点测这条主线（拿你手上一个真实单平行走一遍）

**① 前台下单**（用 agent1）
- 搜套票 / 机票 → 选去/回日期、人数、房间 → 加入购物车
- 购物车里**勾选**要结的产品（可只结一部分，未勾的留着）
- 填出行人（**可拍护照自动识别**，也可手填）→ 结算

**② 后台接单 / 管理**（用 admin）
- 订单管理：**按出行日期筛选**、看去程/回程**出票状态**、看订单**备注**（用房/签证信息）
- **认领接单**（防止漏单 / 重复处理）、改订单状态

**③ 出票 / 履约准备**
- **一键导 PNR Excel**（航司提交格式）
- **一键打包下载护照图片**
- **套票拼房**（按星级 / 性别 / 备注分房）
- **操作部待办 / 特殊提醒**列表

> 重点反馈：**哪一步比你现在 Excel/手工慢？** 哪里要点太多次、找不到、和你预期不一样？
