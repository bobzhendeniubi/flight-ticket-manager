> 给**顾客和代理**看的完整功能说明，也供客服同事答疑时查阅。看到不常见的词会用大白话解释。
> 最后更新：2026-07-09（覆盖 0709 新功能：护照自助补录 / 申请改签 / 下载行程单）

**怎么进**：点微信群里发的链接最省事；自己输地址是 `http://47.83.249.163/`。浏览器提示"不安全"是正常的（还没换正式网址），点"继续访问"即可，**不要自己加 https 的 s**。

**要不要登录**：逛和看不用登录；下单可以**游客身份**（凭订单号+手机号查单），也可以**登录下单**（订单进"我的订单"，能自助退改/补资料/下行程单——功能多得多，推荐）。顾客账号**不能自己注册**，由销售代理或客服开通（登录页写着"还没有账号？请联系您的销售代理为您开通"）。

**换语言**：顶部导航栏的 `中 / EN / VI` 分段按钮（手机在抽屉菜单"语言"区），支持中文/英文/越南语，选一次记住。

**AI 助手**：右下角蓝紫色圆钮，全站可用（beta）。直接说人话："明天去岘港 2 个人"，它会帮你搜航班报价；还能「📎 上传护照」自动识别，识别的信息会带到结账页自动填好。

## 一、逛与选（五类产品）

顶部导航：**套餐 → 机票 → 酒店 → 地面服务 → 签证**。顶部搜索框全站通搜（如输 `QH9588`、`岘港`、`接送`），结果按品类分组。

### 1. 一价全含套餐（首页）
- 打开网站默认就是套餐列表：往返机票 + 岘港酒店含双早 + 签证代办 + 当地接送 + 中文客服，一个价全包。
- 顶部选**出发日期**（默认帮你选好最近可出发日"今天+3 天"）和**成人/儿童/婴儿**人数；回程日期按套餐住宿晚数自动算，房间数按房型能住几人自动算。
- **每张套餐卡可以单独改日期**，价格实时重算（机票随日期浮动）；显示房量档位（如"余量紧张"，不显示精确数字）。机位或房量售罄时"加入购物车"会变灰并提示换日期。
- 卡内可**即选即享**两个升级：「单人入住（一人一间房）」（自动加单人房差价）、「升级商务舱」（占真实商务舱库存，售罄选不了）。
- 排序：推荐 / 价格低→高 / 价格高→低 / 好评优先 / 热度优先。
- 套餐详情页多了：套餐包含 / 费用不含、行程说明、退改政策、常见问题、真实评价。

### 2. 机票（导航"机票"）
- 选出发/到达机场（可一键互换）、去程/回程日期、舱等、人数。
- 每个舱位卡显示价格、行李额和**余位档位徽章**（余位充足/紧张/少量/极少量——只给档位不给精确数）。
- 两个实用按钮（需登录）：
  - **「锁位」**：下单前先占住座位，单次最多 9 张，**固定 10 分钟**，到时自动放回。适合"客人在确认、怕票没了"。
  - **「候补登记」**：售罄时登记 1–9 张 + 手机号，有位后按先来先到人工通知。
- 机票详情页：行程时刻线、舱位选择、行李规则、退改政策（出发前 7 天免费取消，7 天内按航司规则收费）、按航线聚合的真实评价。

### 3. 酒店
- 筛选：城市（岘港/会安）、星级、设施多选；排序同上。
- 酒店详情：图廊、**选房型**（选入住/退房日期后显示各房型的房量档位）、酒店设施、位置周边、评价。房型行可「加入购物车」或「立即预订」。

### 4. 地面服务（接送）
- 筛选：关键字（酒店名/航站楼）、车型、乘车人数；排序同上。详情页有车型路线和评价。

### 5. 签证
- 筛选：关键字（国家）、办理时长（7/15/30 天内）；排序同上。

## 二、下单

### 1. 购物车
- **只有勾选的商品才进结算**，没勾的留在车里（可以攒着）。支持全选、调数量、删除、清空。
- 底部实时显示"已选 X 件 · 已选合计 ¥…"，点「结算所选 N 件」去结账。

### 2. 结账（三步：确认信息 → 填写出行人 → 提交）
- **未登录时先二选一**：「登录后下单」（推荐，订单进"我的订单"可自助管理）或「以游客身份继续」（凭订单号+手机号查单）。
- **联系人**：游客下单手机号必填——后续查订单全靠它。
- **出行人**：姓名（与护照一致）、护照号、联系电话必填；出生日期、国籍/地区（澳门/香港/中国/台湾）、签发地选填。人数会按所买产品自动对齐，少填会提示差几位。
- **「📷 上传护照 OCR」**：给每位出行人拍照/传护照图，**手机浏览器里就地识别**（图不出手机就识别完），自动填姓名/护照号/出生日期/国籍；命中护照底部机读码时还会带出性别/有效期/签发地。识别失败也没关系，照片会保留，手工填就行。
- **支付方式**：微信支付 / 支付宝 / 信用卡；**代理登录**多一项「代理预付余额」（显示本单抵扣后余额）。
- 页面明确说明：**提交后订单状态是"待确认"，客服会联系确认收款，不会立即在线扣款**（提交即锁价）。优惠码暂不可用（输入框是灰的，不是坏了）。

### 3. 下单成功后
- 显示订单号 + 座位保留倒计时（机票单；超时座位释放需重下）。
- 页面内直接给**收款码 + 「上传付款凭证」**：转完账把截图传上来，客服人工核对后订单状态才更新。
- 登录用户点「查看我的订单」；游客记好订单号，去「查订单」跟进。

## 三、我的订单（登录后的自助中心）

顶部导航「查订单」旁的「我的订单」。这里是自助功能最全的地方。

### 订单状态含义速查

| 徽章 | 意思 | 徽章 | 意思 |
|---|---|---|---|
| 待支付 | 等付款 | 退款审核中 | 已申请取消，等审核 |
| 已支付 | 钱到了 | 已退款 | 退款完成 |
| 处理中 | 出票/办理中 | **改签审核中** | 已申请改签，等运营联系 |
| 已出票 | 票出了 | **已改签** | 改签完成 |
| 已完成 | 行程结束 | 支付超时 | 超时未付，座位已释放 |
| 已取消 | 已取消 | 失败 | 出票失败，联系客服 |

### 每张订单卡能做什么（按钮什么时候出现）

| 操作 | 什么状态下出现 | 说明 |
|---|---|---|
| 查看详情 → | 任何状态 | 展开看出行人、项目明细（有航变会标红"航变"和新时刻）、联系人 |
| 上传付款凭证 | 还有尾款没结清时 | 展开详情里有收款码和「上传付款凭证」，传转账截图，人工核对后更新状态 |
| **补充护照资料** | 待支付/已支付/处理中 | 见下面"护照自助补录"。出票后锁定，改资料要找客服 |
| **申请改签** | 已支付/处理中/已出票 | 见下面"申请改签" |
| 申请取消 | 已支付/处理中/已出票 | 先给你算账：已支付/手续费(x%)/预计可退，确认后进"退款审核中"，审核通过 1-3 个工作日原路退回 |
| **下载行程单** | 已支付/处理中/已出票/已完成/改签中/已改签 | 生成 PDF `行程单-订单号.pdf`。订单不含航班会提示暂不支持 |
| 写评价 | 已完成 | 评过一次就不能重复评 |

### 护照自助补录（0709 新）
1. 展开订单详情，每位出行人有徽章：**「护照已上传」**（绿）/ **「待补护照」**（黄）。缺护照时顶部有横幅"待补护照资料 N 人——出票需要护照信息"。
2. 点「补充护照资料」（或「修改护照资料」）打开弹窗 →「上传护照并自动识别」，进度条走完自动填空着的字段，提示"已自动识别，请核对下方信息后保存"。
3. 能改：中文姓名、性别、证件号、出生日期、国籍、护照有效期/签发日期/签发国/签发地。**姓名不能自己改**（换人/改名请联系客服——防止偷偷换人）。
4. 「保存护照资料」→ 行内提示"XX 的护照资料已更新"。如果提示"当前订单状态不可修改"，说明已出票锁定，找客服。

### 申请改签（0709 新）
1. 点「申请改签」，写清楚**想改到的日期/航班**（必填，2 字以上）。提交前不会扣任何钱。
2. 提交后订单变**「改签审核中」**，卡上显示"改签申请处理中，如需补充信息请联系客服"。运营会尽快联系确认差价和新航班。
3. 提示"当前订单状态不支持改签"就联系客服人工处理。

### 顶部两个小板块
- **我的锁位**：锁的座位在这里倒计时（mm:ss），可提前「释放」；归零自动消失。
- **我的候补**：显示"等待中/已通知"，可「取消」。

## 四、免登录查单（游客必看）

导航「查订单」：输**订单号 + 下单时的手机号（或邮箱）** → 显示脱敏的订单卡（状态、金额、项目、出行日期、出行人打码姓名）。
- 待支付的单可以直接在这里看收款码、**「提交付款凭证」**。
- 取消/改签/补资料需要登录账号操作；游客请联系客服。

## 五、代理专区（代理账号登录后多出来的）

- **我的分成**（导航「我的分成」）：应得佣金、下级累计佣金、待打款金额 KPI；按月/状态/范围（自己+下级）筛结算单；点开看逐笔佣金明细（订单/费率/金额）。结算单状态：草稿 → 待审批 → 已核准 → 已支付。这里只能看，审批打款在处理台。
- **我的团队**（导航「团队」）：树形看下级代理（层级/联系方式/订单数/预付余额），**「+ 创建下级代理」**给自己开下级（填邮箱/初始密码/公司/联系人/初始余额）。
- **代理预付余额下单**：结账时多一个支付方式，显示本单抵扣和剩余；余额不足会提示。充值（认款）在处理台的「余额与认款」页提交。

## 六、常见问题

| 问题 | 答案 |
|---|---|
| 付了钱状态怎么没变？ | 到账是**人工核对**的，传了凭证后等客服确认；确认后状态才更新 |
| 座位锁了多久？ | 10 分钟，到时自动放回。要更久就先下单 |
| 想换出行人/改名字 | 自助改不了（防冒用），联系客服 |
| 行程单下载不了 | 订单里没有航班的（纯酒店/签证单）暂不支持；刚支付的稍等片刻再试 |
| 顾客怎么注册账号？ | 不能自注册，找销售代理或客服开通 |
| 优惠码怎么是灰的？ | 功能暂未开放，不是坏了 |
| 帮助中心在哪 | 页脚/导航「帮助中心」有预订须知、退改规则 FAQ；「联系我们」有客服方式 |
