# 一、概览

## 仪表盘（概览 → 仪表盘）
一屏看今天：**今日营收**（对比昨日）、**今日订单**、**待支付订单**（要人工跟进的）、**活跃代理**（近 30 天下过单）四张卡 + 近 7 天营收柱图 + 本月 Top5 代理 + 实时动态 + 最新订单表（「查看全部 →」跳订单管理）。纯看板，没有操作。注意这里的"营收"是当日 GMV 口径，和财务页的核算口径不是一回事。

# 二、运营

## 订单管理（运营 → 订单）——最重要的一页

订单从建到收尾全在这。状态流：草稿 → 待支付 → 已支付 → 处理中 → 已出票 → 已完成；旁路有 已取消 / 超时 / 退款申请中 / 已退款 / 改期申请中 / 已改期 / 出票失败。

### 建单
- **「＋ 录单」**：单笔录单。
- **「＋ 批量创单」**：按航班班次批量录散客，**每位乘客一张单**。里面有 **「📋 粘贴名单导入（OTA 线上单）」**——把 OTA 名单文本整段贴进来（航段+日期、每人姓名/性别/生日/护照/有效期、结算价），自动解析，有问题逐条提示。价格两种填法二选一：**「结算价/人」**（团队议价价）或 **「结算单价（手动）」**（OTA 价，差额自动生成价格调整行）。

### 找单（筛选器）
状态 / 产品类型 / 渠道 / 代理 / 关键词 / 航班号 / 乘客姓名 / **接单状态**（未接单🆕、我接的）/ **开票筛选**（去程·回程·系统 × 已开·未开）/ 签证状态 / 下单时间区间 / 出行日期区间。列表还有"代理分销统计"卡（点代理名直接过滤）。

### 表格上直接看的
尾款列颜色：**琥珀=还欠钱、绿=结清、蓝=多付了**。开票列三个点（去·回·系统）✓已开 ✗未开。

### 订单详情抽屉（点单打开）
- **收款**：「确认收款」（金额默认=尾款，选微信/支付宝/银行转账/代理预付，传水单截图）。欠款且是代理单 →「用代理余额抵」；**多付了** →「存入代理余额」（代理单）或「转挂账池」（进收款对账台等认领）。月结代理不催尾款，挂月结。
- **产品行操作**：机票行「改期」（换班次/舱位+改期费，座位跟着挪，新班售罄会被拒）；「改结算价」（仅管理员）；酒店行「换酒店」。
- **分房**：「🛏 分房 / 调整分房」——拖出行人名字进房间决定拼房（和房控页同款编辑器）。
- **开票（六态）**：去程 / 回程 / 系统 三个独立开关。翻"已开"时校验该班次开票上限。
- **乘客**：护照号/生日/国籍可编辑（前台客人自助补录的资料也在这里核对）。
- **接单**：「🙋 我来接单」认领跟单责任人。
- **待办**：「+ 加待办」（比如"2 日内拿批文"）——会进"提醒中心"。
- **删除订单**：软删进回收站。**仍占座的单删不了**，要先取消释放座位；还有已收款没退完的也删不了。

### 批量与导出
- 勾选多单 →「💰 批量到账」（逐单填金额，共享水单）/ 批量改状态（管理员可强制，注意：把已取消的单强拉回来会**重新占座**）。
- 导出全家桶：「📥 导出 CSV」（当前筛选结果）；模板导出（全岗 / 票务 / 签证三种 xlsx，**勾选了订单就只导勾选的**）；「📊 导出全岗总表」（一行一乘客，按出行日期）；「🎫 票务开票导出」（选出发日+航段+开票状态，直接出航司 PNR 模板）。
- **「🗑 回收站」**（仅管理员）：看已删订单，「恢复」回删除前状态。

## 航班管理（运营 → 航班）
维护自营航班与库存价格：「+ 新建航班」；每条航线「查看班次」（月历库存视图）、「+ 新班次」、「📅 批量加班次」（按星期几循环生成，先预览）、「🗑️ 批量删除班次」（已售班次自动跳过）、「整线停售/恢复」。
班次上：**「⚡ 批量改价 / 仓位阶梯」**——每个舱位设阶梯价（卖掉一档跳下一档价，卖超按最后一档），也可单班改容量/价格。每班次可「导出整班订单」/「导出整班·全岗」xlsx。
注意：改容量/价格立即刷新前台余位显示。

## 座位统计（运营 → 座位统计）
只读看板：班次数/总座位/已售/空舱率 KPI + 每班余票表（**余票 <20 标红**）。余票口径=容量−已售−锁位（和前台一致）。

## 切位·包位（运营 → 切位）⚠️ 演示功能
给代理锁库存份额的页面，**目前是演示版：所有操作刷新页面就没了，不写数据库**（页面自己也有琥珀色提示）。界面流程可以先熟悉：新建切位（选代理/舱位/数量≤散客池）、批量切位、回收过期切位。正式版排在后续里程碑。

## 房控（运营 → 房控）
酒店切房台账。核心是**销控矩阵**（酒店×日期）：每家四行=包房/用房/物理房间/**余量**（红底=超卖、黄=售罄、"未配"=那天根本没配包房周期，不是超卖）。点任意余量格下钻看当晚占的是哪些订单（可复制订单号/换酒店/跳订单页）。
- 顶部**提醒线横幅**：超卖要加房、富余可退房、拼房落单临近，带数量。
- **「+ 新增周期」**：录包房（酒店×日期段×间数×切房单价）；逐行改/删。
- **导出分房表**（成都格式 xlsx，按入住区间或按出发日两种口径）、**导出房态**（矩阵原样出 xlsx）、**导出护照（按酒店）**（选酒店+入住区间，护照图按订单打包 zip，缺图的写进 README）。
- **订单分房**：输订单号 → 拖名字进房间 → 保存。
- 拼房口径：拼房客各算 0.5 间；证件号为 N/A 的占位人不进分房池。

## 签证台（运营 → 签证台）
签证岗工作台。按状态筛任务（默认"待处理+材料准备"）+ 出发日期筛。
- 勾选任务 → 批量标记「已送签材料准备」或「已送签」（一次最多 100 条）。
- 每行展开看乘客名单：护照缩略图点开大图核对、缺护照标红"缺"、「下载护照」打包本单 zip。
- **「打包下载该日签证资料」**：选出发日，一键出该日合并签证名单 xlsx + 全部护照 zip。

## 提醒中心（运营 → 提醒中心）0709 新
所有运营待办集中处理。**每天上班点一次「⚡ 生成今日提醒」**，系统按四条规则自动扫描生成（已存在的自动跳过，不会重复）：
1. **催尾款**：14 天内出发还欠尾款的单（3 天内出发升级为"紧急"）
2. **出行提醒**：3 天内出发的单（确认集合/证件/接送）
3. **护照有效期不足**：乘客护照距出发不足 6 个月
4. **签证缺件**：在办签证但缺护照照片的单
用法：看到自己负责的 →「认领」→ 办完（比如微信催过款了）→「完成」；不用办的「跳过」（必须填原因）；接不动的「释放」给别人。可筛：状态/优先级/来源（自动生成或手动创建）/只看我认领的。到期日过了会标红"逾期"。手动待办从订单详情「+ 加待办」进来。

## 工单看板（运营 → 工单看板）0709 新
操作部的履约总看板：**待处理 / 进行中 / 已确认 / 失败** 四列，覆盖出票、酒店确认、签证送签、接送安排、套餐五类工单（订单付款后自动生成）。
- 卡片按出发时间排，**出发 ≤48 小时还没完成的标红 ⏰，≤72 小时琥珀，已过出发未确认红字**——每天先清红的。
- 类型筛选 + 「只看指派给我的」。
- 勾选多卡 → 底部批量「开始处理 / 确认完成 / 标记失败」。
- 顶部 KPI：待处理数、**48 小时内未完成数（红）**、进行中、今日已确认。

# 三、产品

## 产品管理（产品 → 产品）
四个页签：🏨酒店 / 🚐地面服务 / 🛂签证 / 🎁套餐。各自「+ 新增 / 编辑 / 删除」（删除是下架不是抹掉，历史订单不受影响）。
**套餐向导**：挑机票+酒店+接送+签证组合，定价填"想卖的价"，系统自动换算整单折扣百分比（机票部分仍随出发日浮动，最终价=当日各项合计×折扣）。可设停售日、团期。

## 取消政策（产品 → 取消政策）
配退款手续费阶梯：「+ 新建策略」选产品类型 → 填阶梯（出发前 X 小时收 Y% 手续费；"-1 小时"档=已出行收 100%）。每类产品一条默认策略（不可删），可以再加只对某个班次/房型生效的覆盖策略。**改完立即生效**——前台客人点"申请取消"时的试算就按这里算。

# 四、客户

## 代理管理（客户 → 代理）
代理层级树（1 级总代到 5 级门店）：KPI、搜索/层级/状态筛选、表格或树形视图。「+ 新建代理」（管理员可建任意层级）/ 行内「+ 下级」。详情抽屉四个页签：基本信息（管理员可切结算方式：**逐单到账 / 月结**）、佣金规则（**暂只读**，调整走线下找管理员）、余额调整（跳转到"余额与认款"页统一办）、散客管理（看归属散客；**代理自己开散客账号暂未开通**，让客人找客服开）。

## 散客管理（客户 → 散客）
所有下过单的散客：按姓名/电话/邮箱/归属/标签筛，点名字看详情，可「✏️ 编辑」（联系方式、证件号、标签[VIP/回头客/新客/蜜月/商务/黑名单]、内部备注）。「📥 导出 CSV」。

## 旅客管理（客户 → 旅客）
从所有订单自动提取去重的**出行人**档案（和"散客"不同：散客=下单的人，旅客=坐飞机的人）。**「姓名+生日」精确查找**是身份核实利器。可编辑护照信息，「📥 导出 CSV」。

# 五、财务

## 结算单（财务 → 结算单）
代理月度佣金结算：每代理每月一张（销售额 → 应得佣金 → 扣分给下级 → 扣预付抵扣 = 应付）。
月初「生成/重算」输入月份（已核准/已支付的不会被重算覆盖）。流转按钮随状态出现：草稿「提交审核/作废」→ 待审核「核准/打回草稿」→ 已核准「💰 标记已支付/撤回审核」。可导 CSV。

## 余额与认款（财务 → 余额与认款）
代理预存余额的进出口：
- **代理视角**：看自己余额、收款码；「提交认款申请」（打款后申报金额+传 1-3 张凭证）；看自己认款记录和审核结果。
- **财务视角**：**「待审核认款」**队列逐笔「确认」（可修正实际到账金额）或「驳回」（必填原因）；「手动调整余额」（正加负扣+原因，全部记审计日志，扣到负数会被拦）。

## 收款对账台（财务 → 收款对账台）
所有进账的总台：五个页签 待认领 / 已认领 / 已退款 / 全部流水 / 收款渠道。
- 「+ 登记新进账」：银行/微信到账但对不上号的钱先登记进来（金额/方式/付款人备注/截图）。
- 每笔可「认领」到订单（按订单号搜，金额默认=剩余，可部分认领、一笔拆多单）或「退款」（必填备注，**退了就不能再认领**）。
- 客人前台自己传的付款凭证、订单多付转挂账的钱，都会出现在这里等认领。
- "收款渠道"页签维护对外展示的收款码（前台和代理认款页展示的就是这里配的）。

## 经营报表（财务 → 经营报表）仅管理员，0709 新
三张核心报表，顶部选日期区间（快捷：最近 30/90 天、本月），**「⬇ 导出 xlsx」**一键四表。
- **销售毛利**：按 产品线 / 渠道（代理分销·会员直订·游客）/ 销售代理 三个维度切换，看订单数/收入/成本/毛利/毛利率。行上有"⚠︎缺 N 项成本"说明该行成本没录全、毛利偏高，先去财务页补成本。
- **应收账龄**：谁欠钱欠多久——0-7 / 8-30 / 31-60 / 61+ 天四桶汇总 + 逐单明细（应收/已收/余额/账龄），按欠款额降序。
- **代理欠款**：按代理汇总应收余额和预存余额，欠得多的排前面——催款名单直接用这张。

## 财务（财务 → 财务）仅管理员
最细的成本核算页（**每次打开都记审计日志**）。五个页签：
- **概览**：区间收入/成本/毛利 KPI + 收入细分（机票/税/房/签证/车/升舱改期/超售等）+ 成本细分（包机分摊/税/燃油/旺季/房/签证/车/导游/赠送/手续费等 16 项）。
- **航班毛利**：按航班 P&L，含载客率、**空座损失**（没卖掉的座位摊的包机成本）、航班贡献毛利。
- **订单毛利**：按订单 P&L，缺成本的标"缺 N"。
- **月度趋势**：3/6/12/24 月收入-成本-毛利柱图。
- **成本维护**：录成本的地方——①航班成本周期（航班×日期段：包机总价/机场税/燃油/旺季附加等，可填负数的机型调整和起降折扣）②按具体班次覆盖 ③产品成本（酒店净房价/签证成本/车队结算价）。**成本不录，毛利就不准**——这是财务日常最重要的一件事。
- 两个导出：「⬇ 全量汇总（按乘客）」和「⬇ 按航班分组」xlsx。

# 六、系统

## 审计日志（系统 → 审计日志）
谁在什么时间从哪个 IP 干了什么，全部留痕（订单改动/收款/删单/财务查看/余额调整…）。可按操作人/对象/严重度筛，点行看逐字段改动前后对比，可导 CSV。只读。

## AI 识别设置（系统 → AI 识别）仅管理员
配置护照 OCR 的 AI 引擎（阿里云 Qwen-VL）：填 API Key（保存后只显示打码，不可反查）、模型 ID、「启用 AI 识别」开关、「测试连接」。**没配或关掉时，录单 OCR 自动回退浏览器本地识别**——功能不中断，精度略降。

# 七、按岗位的一天（速查）

| 岗位 | 每天动线 |
|---|---|
| 运营/客服 | 仪表盘扫一眼 → **提醒中心「生成今日提醒」清待办** → 订单管理处理新单（接单/收款/催尾款）→ 前台客人提交的改签申请（订单状态"改期申请中"+提醒中心有待办）逐个联系确认 |
| 票务岗 | 工单看板筛"出票"清红卡 → 订单管理「🎫 票务开票导出」出 PNR 模板 → 出票后翻开票开关 |
| 签证岗 | 签证台看缺件（提醒中心也会有"签证缺件"待办）→ 收齐后批量标"已送签" → 出发前打包该日资料 |
| 房控 | 房控页看提醒线（超卖/富余）→ 维护包房周期 → 出发前导分房表/房态/护照 zip |
| 财务 | 收款对账台认领进账 → 余额与认款审代理认款 → 财务页补成本 → 经营报表看毛利/账龄/催款名单 → 月初生成结算单走审批 |
| 管理员 | 以上全部 + 回收站/强制改状态（异常单）+ 审计日志抽查 + 取消政策/AI 设置维护 |

# 八、这些是"故意的"，别当成坏了
