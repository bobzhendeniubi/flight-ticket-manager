一、代理立减规则怎么配

「结算价日历上的价是对外价，对每家代理还要再减 180～210」——这件事在系统里叫 立减规则。 配好之后，录单时选中该代理，系统自动在结算价上把这个数减掉，不用手算、也不用下单后再去改价。

1. 进哪个页面

左边菜单 产品 → 立减规则。

2. 三个页签分别什么意思

页签什么时候用
代理专属这一家代理有自己的数。优先级最高，配了就以它为准。
例：世途1 / 世途2 减 180，世途3 / 世途9 减 190，TY 减 210 —— 各家不一样，就各配各的。
代理默认兜底：没配「代理专属」的代理走这一档。不绑定具体代理，配一遍全体通用。
散客前台散客用的，和代理无关。这次不用动它。
省事顺序：先兜底、再补特殊。
如果大部分代理是同一个数（比如都 190），先在「代理默认」把 190 铺一遍； 然后只给数字不一样的几家（180 的、210 的）在「代理专属」单独配。 这样要填的条数少一大半，而且以后新签的代理自动就有兜底值，不会漏配。

3. 一条规则要填的六个格子

格子怎么填
档次市区三星 / 市区四星 / 市区五星 / 国际五星，四选一。要和套餐的结算档次对上，对不上这条不会命中。
晚数1～5 晚。同样要和套餐的结算晚数对上。
出发日窗口按客人出发日判定（不是下单日）。
长期政策不想天天维护，窗口就开长一点（比如 2026-01-01 ~ 2029-12-31），一次配完省心。
立减 ¥/人每人减多少钱。填 190 就是每人减 190。
启用打勾才生效。政策暂停时把勾去掉即可，不必删规则。
备注选填。建议写清这条是什么政策，以后自己或同事看得懂。
一家代理要配几条？＝ 你们实际在卖的「档次 × 晚数」组合数。
规则按「档次 + 晚数」精确匹配，所以卖几种组合就配几条。 比如只卖「四星2晚」和「五星2晚」，那一家代理配 2 条就够，不用把 4 档次 × 5 晚数全填满。
没配到的组合不会命中立减，录单试算里就看不到立减行——这也是自查漏配的办法（见下一章）。
同一组（同档次 + 同晚数）的启用窗口不能重叠。
比如「市区四星 · 2晚」已经有一条 2026-01-01 ~ 2029-12-31，就不能再加一条 2026-06-01 ~ 2026-08-31。 要做旺季特殊价，得把原来那条的窗口先切开（改成 05-31 结束，再新建 09-01 开始的），中间那段单独配。

二、配完怎么验证真的生效了

别靠猜，录一单试试就知道。不用真提交，走到试算那一步就能看到。

  1. 订单管理 → ＋ 录单 → 产品类型选 套餐。
  2. 选一个已经配了结算档次的套餐，填好出发日期和人数。
  3. 归属代理选中你刚配了立减的那家。
  4. 看下方的系统价试算。
 弹窗 — 单笔录单 · 系统价试算
套餐（结算价日历）　市区四星 · 2晚 · 出发 2026-10-01　¥2,860/人 × 2 人　＝ ¥5,720
同业立减 ¥190/人 × 2 人　＝ −¥380　← 配对了就会出现这一行
合计 ¥5,340
看到「同业立减」这一行 = 配对了。金额和人数也一起核一眼。
没出现这一行？按这个顺序自查：
  1. 代理选对了吗？（选成「直客」不会命中代理立减）
  2. 这个套餐配了结算档次和晚数吗？没配的套餐不走结算价日历，也就没有立减。去 产品 → 套餐 里检查。
  3. 规则的档次 / 晚数和套餐的对得上吗？差一档就不命中。
  4. 客人的出发日落在规则的窗口里吗？
  5. 规则的「启用」打勾了吗？改完点「批量保存」了吗？

三、指定酒店加价怎么配

「除随机酒店之外的酒店都是加钱指定酒店，需要联动结算价 +40」——这件事系统也已经能做， 叫 指定酒店加价。配好后：录单时在套餐里指定某家酒店，系统自动按占座人数加收， 而且这笔加价会自动叠进结算价，不用你另外再加。

1. 在哪儿配

左边菜单 产品 → 酒店 → 找到那家酒店 → 编辑 → 找到这一格：

 弹窗 — 编辑酒店
每晚起价（前台展示价）680 指定酒店加价（¥/人，0 = 不加价）140
1就是这一格。填 40 = 客人点名要住这家，每人加收 40。
这个数是「一店一配」，不是全局统一。
系统按每家酒店各自配加价——因为各家和我们的差价本来就不一样，豪华店通常远不止 40。
所以要逐家去填。如果确认目前所有非随机酒店都是统一加 40，那就每家都填 40； 哪天某家谈成了别的价，单独改那一家，不影响别家。
没填 = 按 ¥0 处理，指定了也不会加钱。

2. 配完长什么样

回到录单（套餐），酒店下拉里会直接把加价标出来，选中后下面还会算给你看：

 弹窗 — 单笔录单 · 套餐 · 酒店
酒店（不选 = 随机）海富酒店（★★★★★ · 指定+¥40/人） 房型标准房
指定酒店加价 ¥40/人 × 2 人（占座人数）＝ ¥80，已计入下方系统价试算。
如果这里显示的是「该酒店未配置『指定酒店加价』（按 ¥0 计）」， 就说明那家酒店的那一格还是空的——回上一步去 产品 → 酒店 里填上。系统会主动提示，不用担心配漏了不知道。
「不选 = 随机」是什么意思？
套餐本身是按星级随机报价的。酒店那一栏留空，就是走随机档、按套餐原价走、不加钱。 只有点名要住某一家时才去选具体酒店，这时才加钱。
新增：下拉里现在分成两组了。
「具体酒店」组是真实酒店；「星级随机档占位」组里那些叫「随机三星 / 随机四星」的不是真实酒店， 是随机档的占位记录。套餐要走随机档，正确做法是把酒店留空，不要去选占位那一组。 万一选了，下面会有橙字提醒你。
同时，如果指定的酒店星级和套餐档次对不上（比如四星套餐指了三星酒店），也会出橙字提醒——只提醒、不拦你提交，确认没选错就照常提交。

四、国际五星档次需要你们确认

这一条要麻烦你们回一句。
结算档次有四档：市区三星 / 市区四星 / 市区五星 / 国际五星。
但「星级随机」目前只有 三星 / 四星 / 五星 三档，没有「国际五星随机」。

也就是说：国际五星的套餐目前没有对应的随机档可选。请确认你们实际是怎么卖的：
  1. 国际五星一律指定具体酒店（不做随机）？→ 那现状就够用，录单时直接指定即可，不用改系统。
  2. 国际五星也要能卖随机？→ 那要开发补一个「国际五星随机」档。
请回一句是哪一种，是第 2 种我们就排进去。

五、「后返」在系统里叫什么

你提到「在这个基础上还有后返」——后返在系统里叫 佣金，是另一条独立的线，和立减不是一回事：

立减佣金（后返）
什么时候发生下单当场，直接减在结算价上事后按规则计提，走结算单
代理看到的结算价本身就已经是减完的结算价不变，另外返
在哪儿配产品 → 立减规则代理管理 → 佣金规则
两者不会互相顶掉，可以同时存在（先立减，再按规则计提佣金）。 如果希望结算单上把「立减 + 后返」合并成一个数展示，请单独提一下，那是另一个改动。

六、常见问题 FAQ

我配了立减，为什么录单时没减？
照第二章那五步自查一遍，九成是「套餐没配结算档次」或者「档次 / 晚数对不上」。
立减是每人减，还是整单减？
每人减。填 190 就是每位出行人减 190，2 个人就是减 380。试算行里会写清楚「¥190/人 × 2 人」。
「出发日窗口」是按下单日还是出发日？
按客人的出发日。今天下的单、明年出发，看的是明年那个日子落在哪条规则的窗口里。
某家代理这个月政策变了，怎么改？
不要直接把旧规则的金额改掉——那样以前的窗口也跟着变了。正确做法：把旧规则的「出发日窗口」结束日改到政策截止那天，再新增一条从次日开始的新规则。这样历史口径可查。
我是录单岗，能自己改立减规则吗？
可以。内部岗位现在都能改（以前只有管理员能改，已经放开了）。每次保存和删除系统都记审计日志，改了什么、谁改的都查得到。
指定酒店加价要不要也按档次分？
不用。它跟着酒店走——一家酒店一个数，和档次、晚数、代理都无关。
指定酒店加价会不会被立减抵掉？
不会。两者是分开的两行：先按日历取结算价、叠上指定酒店加价，再减立减。试算里逐行看得到。
