几个字段的意思，用大白话说：

字段怎么填
每晚起价（前台展示价）客人在前台商城看到的价格起点。不是我们跟酒店的进货价。
价格系数每个房型的实际每晚价 = 每晚起价 × 这个系数。标准房填 1.0，海景房贵一点就填 1.15 之类。
成本价（¥/晚，仅内部）我们拿房的净房价，只有内部同事能看到，客人看不到。填了财务算毛利才准，尽量别空着。
可住人数 / 大人 / 小孩这间房睡几个人。分房的时候系统按它判断一间房装几个人。
删除酒店 = 下架，不会把历史订单弄丢；但已上架卖过的酒店别随便删，先问运营。
在房控页的酒店下拉菜单里找不到某家酒店？就是这里还没录——先来这里新增，再回房控页。

三、包房周期：告诉系统「我们切了多少间房」

「包房周期」就是记账：某家酒店、某段日期，我们切（包）了多少间、单价多少。不录周期，系统就不知道你手里有多少房，销控矩阵会显示「未配」。

位置：房控页拉到最下面的「包房周期管理」卡片。

1点右上 + 新增周期。
2选酒店 → 填起始日、结束日 → 填「间数」（这段日期每天切几间）→ 填「切房单价(¥/间/晚)」→ 备注可空 → 保存。
3要改就点那一行的 改，要删点 删（会弹确认：删了之后那段日期的「包房」数会跟着减少）。
包房周期管理（按 酒店 × 日期段 定切房间数 / 单价；周期可叠加）+ 新增周期
酒店起始结束间数单价(¥/间/晚)备注
岘港海岸酒店2026-08-012026-08-3110¥6508月切位改 删
岘港海岸酒店2026-08-152026-08-205¥700旺季加切改 删
周期可以叠加：上面例子里 8月15–20日 这家酒店每天的「包房」= 10 + 5 = 15 间
酒店临时给你加房？不用改旧周期，直接再加一条新周期叠上去就行，方便日后对账。

看最后一行「余量」的颜色就够了：红 = 超卖，缺房　浅黄 = 0，卖光了　未配 = 那天没录包房周期（不是超卖，先去补周期）

四行分别是什么：

行意思
包房那天我们切了多少间（= 当天所有包房周期的间数加起来）。
用房（床位）订单占了多少「床位」。拼房的客人一个人算 0.5，所以可能出现 6.5 这种小数。这是算钱用的口径。
物理房间实际要开几间房。规矩：同性两位拼房客拼 1 间；男女不能拼一间；落单的、性别没填的，各自独占 1 间。
余量= 包房 − 物理房间。真正能不能收客看这行。

「用房」格子上带 拼 小标：当晚有拼房客配不上对（比如 3 男 2 女，落单 1 男）——要么补收单房差让他单住，要么再想办法配对。

4.3 点余量格子：看是谁占的房

任何一个「余量」格子都能点。点开右侧弹出小抽屉，列出当晚每一张占房订单：订单号、状态、联系人、几人几间、乘客名单、入住~退房、归属代理。每张订单下面有三个动作：

按钮干什么
复制订单号把订单号复制走，去订单页粘贴搜索。
换酒店超卖了要挪单？直接在这里给这张订单换一家酒店，换完矩阵自动刷新。
去订单页 →跳到订单管理页看详情。

4.4 远期总量

销控矩阵下面还有一张「远期总量」表：不分酒店，按天合计——收客（订单占的）/ 控房（切的）/ 余房（差值）。用来看大盘：未来哪几天房紧、哪几天房松。

五、给订单分房（拼房 / 整间 / 单人入住差价）

5.1 两个入口，用哪个都一样

入口怎么走适合什么时候
房控页房控页「订单分房（拖拽）」卡片 → 输订单号（如 ST-20260625-0001）→ 查订单手里有订单号，批量处理一串订单时。
订单页运营 → 订单 → 点开某张订单 → 「酒店情况 · 拼房」卡片 → 🛏 分房（已分过则显示「调整分房」）正在看这张订单时顺手分。含酒店但还没分房的订单，这里会用黄字提醒「应分房 · 尚未分房」。

左边是还没分的人（名字旁标男/女），把名字拖进右边的房间盒子；「半间(拼房)」按钮是拼房的开关

3每个盒子下面两个小格：房型（选填，如「大床房」「双床房」）、备注（选填）。备注会一路带进分房表，酒店和地接都看得到——见 5.4。

5.3 「半间(拼房)」和「整间」是什么意思

整间（默认）半间(拼房)
什么情况用这个盒子里的人独占一整间房（一个人单住、一家人一间，都算整间）。盒子里的客人是「拼房价」卖出去的——每人只买了半间床位。点一下 半间(拼房) 按钮，盒子上出现 ½ 半间 标。
算账口径算 1 间。每盒算 0.5 间。比如 7 个拼房客 = 3.5 间床位。
分房表里房号显示「房3」。房号显示「房3(½)」，备注自动带「半间/拼房」。
男女不能拼一间。拼房客如果凑不成对（奇数、或性别没录），销控矩阵会标 拼、临近出发提醒线会报「拼房落单」——处理办法就两条：让客人补单人入住差价改单住，或者另找同性客人配对。

5.4 单人入住差价（补收单房差）

拼房客最后没人跟他拼、要一个人住一间时，公司要多收「单房差」。操作在订单详情里：

1订单管理 → 点开这张订单 → 「酒店情况 · 拼房」卡片右上角，点黄色小字 补收单房差。
2填「每晚金额」（整数，比如 300）×「晚数」（默认按套餐晚数带出，可改，1–60）；下面会自动算合计。备注可写「客户单人入住」。
3「转单住乘客」下拉（重要）：选出是哪位客人转单住——选了之后系统会把他标记为单人入住，套餐的计费房数自动按「独住占一间」重算，房控和分房自动跟着变。如果只是收钱、房态不用动，就选「不联动」。已经标过单住的人是灰的，不能重复选。
4点 确认补收 → 再确认一次弹窗。系统会在订单里加一条费用行，钱计入这张订单的应收 / 尾款，收款由运营 / 财务跟进。
这笔差价多少钱，按公司当期的口径收，拿不准先问运营，别自己拍。

六、导出分房表：给酒店递名单

位置：房控页上方「导出分房表」卡片。这是你交给酒店 / 地接的入住名单（Excel）。

6.1 两种导出口径，先选对

口径选什么导出来的是什么时候用
按入住区间入住起 ~ 入住止（最长 14 天，超了会报错）这段日期入住的所有客人。每个入住日期一个工作表（表名像「7-10」），表内按酒店分组。给某家酒店对某几天的房。
按出发日一个出发日那天出发的所有订单的整段住宿——住几晚就出现在几个工作表里。按团（出发日）给地接发整团名单。
1点选「按入住区间」或「按出发日」→ 选日期 → 点 导出分房表，浏览器会下载一个 .xlsx 文件。

6.2 表里的列怎么读

一行 = 一位客人。前面是老样式名单一样的列（代理机构、备注、酒店类型、中文名称、乘客姓名、出发(往返)日期、结算价格、生日、性别、证件编号、签发/有效日期、录入时间、房型），最后三列是新系统特有的，重点看两列：

序号中文名称乘客姓名房型房间号升级原因当日余房备注
1张三ZHANG, SAN双床房房13
2李四LI, SI双床房房13
3赵梅ZHAO, MEI大床房房2(½)3要高楼层 / 半间/拼房
4WANG, WU大床房房33
同一个「房N」= 住同一间；带「(½)」= 拼房半间。中文名空着 = 这位客人还没录中文名，去订单里补
房间号列显示意思
房1、房2…（同号相邻）号一样的人住同一间。你手工分的房，原样按组出。
房2(½)这一间是「半间/拼房」组，备注列也会自动带「半间/拼房」字样。
没手工分房的客人系统自动编号：男客一批、女客一批，按房型能住的人数装满一间开下一间；性别没录的客人各自单独一间（保险起见不给拼）。自动编的房号排在手工分的后面。所以名单不会有人漏房号——但自动分的只是兜底，正式名单前最好还是手工分好。
当日余房列显示意思
数字（如 3）这位客人入住当晚，这家酒店在销控上还剩几间。负数 = 已超卖。
未配那晚没录包房周期——回第三章补。
—系统对不上这位客人到底归哪家酒店（一般是手工分房时填的酒店名和订单里的酒店对不上），宁可空着不瞎标。碰到就把分房重新保存一遍或找运营看。

另外：「结算价格」列是人均（订单总价 ÷ 人数）；「飞行次数」「升级原因」两列目前系统没有数据，固定留空，是正常的。

七、导出房态 / 导出护照

7.1 导出房态

房控页「导出房态（销控矩阵）」卡片：选起始 / 截止（最长 120 天）→ 点 导出房态。导出的 Excel 和你屏幕上看到的销控矩阵一模一样（每家酒店 包房/用房/物理房间/余量 四行，含「未配包房」标记），发群里汇报房态很方便。

7.2 导出护照（按酒店）——给酒店 / 地接递证件

1还是这张卡片里，下半部分「导出护照（按酒店）」：选一家酒店 + 入住起 / 入住止。
2点 导出护照 → 下载一个 zip 压缩包：这段日期入住这家酒店的所有客人的护照图片，按订单号分文件夹。
3先打开包里的 README.txt 看一眼：哪位客人还没传护照图，都列在里面——缺的去催运营 / 客人补。

酒店下拉里只有当前销控板日期范围内出现过的酒店；找不到就先把页面顶部的日期范围调大。

7.3 导出护照（按姓名）——临时凑名单用

不限酒店，把一串姓名（逗号、顿号、空格、换行分隔都行，一次最多 100 个）贴进输入框，可以再选一个出发日期范围过滤（留空 = 不限），点 导出护照(按姓名)。zip 按出发日期分文件夹、按姓名命名文件。中文名要一字不差；护照上的拼音名不分大小写。

八、和运营、录单同事怎么配合

场景约定的做法
客人有酒店方面的要求
（指定酒店、要拼房、要高楼层、蜜月布置…）		让录单同事在录单时填进「酒店情况（选填）」这一栏。它会显示在订单详情的「酒店备注」里——你分房前先看这一栏，再照着落实到分房上。
要求落到分房上能用结构表达的用结构：谁和谁一间 = 拖进同一个盒子；拼房 = 切「半间(拼房)」。剩下没法结构化的（「和某人不分开」「要高楼层」）写进房间盒子的备注——它会带进分房表的备注列，酒店直接看得到。
订单里看拼房情况订单详情「酒店情况 · 拼房」卡片会显示一句摘要，比如「整间 双床房：张三、李四；半间(拼房)：赵梅、钱丽」。没分房会黄字提醒「应分房 · 尚未分房」。
客人改单住 / 收单房差你在订单详情点「补收单房差」并选好「转单住乘客」（见 5.4）；收钱这一步由运营 / 财务在订单里确认收款，你不用碰钱。
超卖挪单 / 换酒店小范围直接在余量格下钻抽屉里「换酒店」；牵扯客人沟通的，先跟运营打招呼再动。
酒店确认工单「工单看板」里的酒店确认类工单归操作部跟；你负责的是房态账和名单准确。
名单里客人少了一个？纯占位的联系人（证件号是 N/A 的）不进分房池、不上名单，这是正常的，不用慌。

九、常见问题 FAQ

Q1：余量是红色负数，怎么办？
真超卖了。两条路：① 找地接 / 酒店加房，加到了就去「包房周期管理」加一条周期把账补平；② 加不到就挑订单「换酒店」挪走。提醒线每天都会用红条催你。
Q2：格子显示「未配」是坏了吗？
不是坏了，也不是超卖——那天你还没录包房周期，系统没法算余量。去「包房周期管理」把那段日期的切房录进去就好了。
Q3：「用房」怎么会有 6.5 间这种小数？
那是床位口径：拼房客一人算 0.5。看实际要开几间房，看下面的「物理房间」行；看能不能收客，看「余量」行。
Q4：「拼」的小黄标是什么意思？
当晚有拼房客配不上对（男女不能拼一间；性别没录的也不给拼）。要么补收单房差让他单住，要么再配一位同性拼房客。临近出发还没处理，提醒线会报「拼房落单」。
Q5：分房时房间盒子删不掉？
盒子里还有人。先把名字拖回左边池子（或拖去别的盒子），空盒子才能删。另外至少要留一个盒子。
Q6：没分房的订单，分房表里会不会漏人？
不会漏。没手工分的客人系统会自动按性别、按房型人数打包编房号兜底。但自动分的不懂客人的要求，正式给酒店的名单，出发前尽量都手工分好。
Q7：分房表「中文名称」一列是空的？
这位客人还没录中文名（系统不会拿护照拼音充数）。去订单详情的乘客区把中文名补上再导。
Q8：导出分房表提示「跨度最多 14 天」？
按入住区间导出一次最多 14 天，分两次导。导房态最长 120 天。
Q9：保存分房时弹出一堆提示，是不是没保存上？
保存上了。那些提示（金额有分叉、一间房里男女混住、订单里有多条酒店行之类）是让你复核的，不拦保存——但别直接点掉不看，有疑问找运营。
Q10：护照 zip 里少了几个人的护照？
打开压缩包里的 README.txt，缺图的客人都列在那——是还没上传护照照片，去催补，不是导出丢了。
Q11：新增包房周期时下拉里没有那家酒店？
酒店还没建档。去 产品管理 › 酒店 新增（第二章），回来就有了。
Q12：补收单房差点了「不联动」，房控数字没变，正常吗？
正常——「不联动」就是只收钱不动房。要让房控 / 分房跟着按单住重算，得在下拉里选出转单住的那位乘客。
