一、关柜时间是怎么算的

关柜时间 = 该班次起飞时间 − 关柜提前分钟数。提前分钟数没填就按系统默认 45 分钟。举例：15:45 起飞、没单独设置 → 15:00 关柜；到了 15:00 就可以标 no-show，不用等到 15:45。

关柜前不能标 no-show。客人临时不飞，走「取消航段 / 取消订单」。
关柜后 → 起飞前可以标 no-show。回程座位不能再释放、也不能恢复。
起飞后照旧：系统起飞满 2 小时自动作废回程；手工作废也在这时才放行。
「能不能登机看柜台关没关，不是飞机推没推出去」——这是整套判定的原则。去程标 no-show、回程放座、恢复回程三处都按这个原则走；只有「作废」仍然按真起飞时刻，因为作废是座位确实消耗掉之后才做的事。

二、给某一班单独设关柜提前分钟数

什么时候要设：某个航司 / 某一班关柜不是提前 45 分钟（比如提前 60 分钟）。其余班次不用管，默认就是 45。

  1. 左侧菜单「航班管理」，展开对应航班，在月历里点那一天的班次格子打开班次详情，面板底部点「改时刻」。
  2. 弹窗里除了出发 / 到达时间，多了一项「关柜提前分钟数」。填整数（0–1440），比如 60。
  3. 留空 = 用系统默认 45 分钟。想改回默认，把数字删掉保存即可。
  4. 保存后立即生效：这一班的 no-show 判定、批量页的「已关柜 / 未关柜」都按新值算。

航班管理 → 展开航班 → 点班次格子 → 班次详情面板底部的「改时刻」

改时刻弹窗：「关柜提前分钟数」选填，留空即默认 45

这个数只影响本班次。同一航班号的不同日期各是各的班次，要每一班都改的话，批量操作里目前不带这一项——通常也不需要，航司规则一般是固定提前量，默认值已经覆盖了大多数情况。

三、订单详情里标 no-show：关柜前 / 关柜后

入口没变：订单详情 → 「no-show 处理」。变的是能不能标的时间点，以及提示文案。

关柜前点进去

面板会直接告诉你还没关柜、什么时候关柜，此时不能标。客人临时不飞请走「取消航段 / 取消订单」。

未关柜：红字写明当地时间几点关柜，「确认」按钮不可用

关柜后点进去

能标了。去程打 no-show 标（钱不动）；有回程的单可以勾「同时释放回程座位」——但要看回程这一班关没关柜，见下一节。

已关柜：可以确认标记；单程单会提示没有回程座位可释放

四、关柜之后到起飞之前，哪些事不能做

这段一般就是 45 分钟。柜台关了，座位就算放回库存也没人能值机——所以：

动作回程那一班关柜后为什么
标去程 no-show可以看的是去程那一班关没关柜
同时释放回程座位不行，勾选会被拦，只能记录 no-show关柜后放回库存的座位没人能值机，等于凭空多卖
恢复回程（代理来要座位）不行占回去也上不了飞机
作废回程要等起飞后（系统起飞满 2 小时自动作废）作废是座位确实消耗掉之后的动作
正常流程不会卡在这里：去程当天关柜后标 no-show，回程通常是隔天甚至更晚，那时回程还没关柜，座位照样能释放、能恢复。只有回程那一班本身已经关柜了，才会碰到上面这几条。

五、no-show 批量处理页的变化

  1. 左侧菜单「no-show 处理」，选班次。班次角标现在显示「已关柜 / 未关柜」而不是已起飞 / 未起飞；未关柜的班次不给提交。
  2. 贴航司名单，点「匹配」。匹配表的订单号下面多了一行订单备注，方便认人；鼠标放上去看全文。
  3. 回程那一列原来写「已出票 / 未出票」，现在写「票务已确认 / 票务未确认」——这是票务任务的状态，跟财务的「开票」不是一回事。

批量页：抬头与班次角标改为关柜口径

匹配表：订单号下带备注；回程列写「票务已确认 / 未确认」
