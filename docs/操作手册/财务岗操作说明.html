一、先把金额口径搞明白

后面所有页面的数字都建立在这三个概念上，先花五分钟读完，后面就不会对不上账。

1. 尾款怎么算

尾款 ＝ （订单总价 ＋ 售后调整费） − 已到账金额 · "售后调整费"指下单之后补收的钱，比如补收单房差、改期费——它们会加进应收里。
· "已到账"包括所有确认过的收款，也包括用代理预存余额抵掉的部分。
· 尾款是正数＝客人还欠钱；等于 0＝结清；负数＝客人多付了（多付的钱有两个去处，见第二章）。

2. 什么叫"人均均摊"（导出表的金额口径）

导出的对账表（比如「导出全岗总表」）是一行一位乘客。为了不让人误以为"每个人都付了全款"，表里所有金额列（结算价格、尾款金额、已到账金额、单房差、签证金额、退款金额、订单成本）都是订单金额 ÷ 出行人数的均摊值。

举例：一张订单 3 位乘客、总价 ¥30,000、已收 ¥21,000。
· 订单页显示：应收 ¥30,000 / 已付 ¥21,000 / 尾款 ¥9,000（整单口径）
· 导出表里每一行显示：结算价格 ¥10,000 / 已到账 ¥7,000 / 尾款 ¥3,000（每人均摊）
所以"导出金额 × 人数 ≈ 订单总价"，两边并不矛盾——只是一个按单、一个按人。

3. 代理预存款（预存余额）是什么

代理可以先把钱打给公司存成"预存余额"，之后下单欠尾款时直接从余额里扣，不用一单一单转账。围绕它有三件事，都是财务的活：

  • 充值（认款）：代理打款后在后台申报，财务在「余额与认款」页审核确认，钱才进余额。→ 第三章
  • 抵扣：代理订单欠尾款且余额够时，在订单详情里点"用代理余额抵"。→ 第二章
  • 回存：代理订单多付时，可以把多出的钱存回该代理的余额。→ 第二章
⚠ 注意区分：预存余额（代理充值的钱）和挂账池（对不上号、待认领的进账）是两个池子。预存余额跟着某个代理走；挂账池的钱不属于谁，要在「收款对账台」认领到具体订单。

二、收款与认款

现阶段收钱全靠"扫码收款 + 人工登记"：客人/代理扫我们的收款码付钱 → 财务见到钱 → 在系统里把这笔钱登记到订单上。系统不会自动到账，客人传了付款截图订单状态也不会自己变，必须人工确认。

1. 给订单确认收款（最常用）

  1. 左侧导航 → 运营 → 订单，找到那张订单（可按订单号/乘客名/航班号筛），点开订单详情。
  2. 往下翻到「收款」区域：先看清"已付 / 应收"和尾款徽标，确认这单确实还欠多少。
  3. 填收款金额——输入框默认提示就是当前尾款，收多少填多少（可以分多次收）。
  4. 选收款方式：银行转账 / 微信 / 支付宝 / 代理预付，按实际打款渠道选。
  5. 上传水单截图（转账凭证，4MB 以内），备注选填（比如"客人分两笔转"）。
  6. 点「确认收款」。已付金额立刻更新，尾款重新计算；收款记录会留在下方列表里，可随时点开截图复查。

2. 欠款的代理订单：用代理余额抵

如果订单归属某个代理、还欠尾款、且该代理预存余额大于 0，收款区会多出一行"用代理余额抵"。填抵扣金额（不能超过尾款、也不能超过余额）后确认，余额被扣掉、订单已付相应增加；抵满尾款后订单自动变为"已支付"。

3. 客人多付了怎么办（尾款是负数）

多付时收款区会出现处理入口，两个去处按情况选：

订单详情 · 多付处理（示意）
已付 / 应收¥32,000 / ¥30,000 多付 ¥2,000
多付 ¥2,000 可存入代理余额  A存入代理余额
多付 ¥2,000 可转挂账池（在收款对账台待认领）  B转挂账池
按钮什么情况用钱去了哪
A存入代理余额（只有代理订单有）代理多转了，钱留着下次抵扣进该代理的预存余额，订单回到刚好结清
B转挂账池（散客/代理订单都有）说不清这笔多付该归谁，或后面要退/要挪到别的订单生成一条"订单多付"进账，去「收款对账台」等认领；订单回到刚好结清

4. 月结代理：不催尾款

结算方式为"月结"的代理，订单欠尾款时不显示琥珀色欠款告警，而是蓝色「月结挂账 ¥9,000」——意思是这笔挂到月底统一对账，不需要逐单催款。代理是逐单到账还是月结，在「客户 → 代理」详情里由管理员设置。

5. 批量到账：一次收了好几单的钱

代理一笔转账付了多张订单时：在订单列表勾选这几张单 → 点「💰 批量到账」→ 弹窗里逐单填到账金额（默认＝各单尾款）→ 共用同一张水单截图 → 提交。已结清/多付的单不会出现在批量到账里，避免重复入账。

三、代理预存款：认款审核与余额调整

位置：左侧导航 → 财务 → 余额与认款。代理打款充值后在这页申报，财务在这页审核；同一页还能手动修正余额。

1. 代理那边看到的是什么（了解即可）

代理登录后台看到的是自己的视角：当前预存余额、我们的收款码（有专属码显示专属码，没有就显示公司统一码）、"提交认款申请"表单（申报金额 + 备注 + 1~3 张付款凭证截图）、以及自己历次申请的审核结果。

2. 财务怎么审（核心操作）

  1. 打开「余额与认款」，最上面就是「待审核认款」队列，右上角有待处理条数。
  2. 逐笔核对：代理是谁、申报金额多少、点开凭证缩略图看转账截图，和银行/微信实际到账对上。
  3. 对上了 → 点「确认」。到账金额默认按申报金额带出，实际到账和申报不一致时可以直接修正（比如申报 ¥10,000 实到 ¥9,998），可填核实备注，点「确认到账」——钱即刻加进该代理的预存余额。
  4. 对不上/有问题 → 点「驳回」，必须填驳回原因（代理那边能看到），钱不入账。

3. 手动调整余额（线下对账修正用）

页面最下方「手动调整余额」：选代理 → 填调整金额（正数加、负数扣）→ 必填调整原因 → 提交。用于线下对账发现的差异修正。两条硬规则：扣减不能把余额扣成负数（会被系统拦下）；每次调整都写入审计日志，有据可查。

2. 登记新进账

银行/微信到了一笔钱但暂时对不上是哪个订单的？先点「＋ 登记新进账」记下来：金额（人民币）、收款方式、付款人备注（比如"王先生 微信尾号1234"）、订单提示号（客户自报的订单号，帮助之后认领，选填）、到账时间（默认现在）、收款截图（6MB 以内，选填）。登记后这笔钱进入"待认领"，挂账余额会加上它。

3. 认领到订单

  1. 在"待认领"页签找到那笔进账，点「认领」。
  2. 输入订单号点「查找」——系统带出该订单的联系人、应收和当前尾款，先核对是不是这单。
  3. 填认领金额（默认＝这笔进账的剩余金额，不能超过剩余）。支持部分认领：一笔进账可以拆着认领到多张订单，认完为止。
  4. 点「确认认领」，二次确认后钱记到订单上，订单已付随之增加。

4. 退款

🚨 点「退款」把剩余金额标记退掉时必须填退款备注（如"重复付款，原路退回"），并且退款后这笔钱不能再认领——点之前想清楚。系统里的"退款"只是记账标记，真正把钱退给客人还是要在银行/微信里人工操作。

5. 另外两个页签

  • 全部流水：进账 + 订单收款合并的只读流水，按时间倒序，日常抽查、和银行流水总额核对用。
  • 收款渠道：维护对外展示的收款码——前台客人付款页、代理认款页看到的二维码就是这里配的。换码、加银行账户信息都在这。

6. 建议的每日动线

☀ 每天上班：打开对账台 → 看"待认领笔数"清零它（逐笔认领/退款）→ 对一眼"今日进账"和银行/微信实际到账 → 切到「余额与认款」清掉待审核认款 → 顺手看一眼经营报表的代理欠款（第九章）。

五、结算单：每月给代理结佣金

位置：左侧导航 → 财务 → 结算单。每个代理每个月一张结算单，算清"这个月我们该付给这个代理多少佣金"。

1. 一张结算单的账怎么看

应付给代理 ＝ 应得佣金 − 分给下级佣金 （＝净佣金） · GMV：该代理当月订单总额（销售额），是算佣金的基数，不是要付的钱。
· 分给下级：多级代理体系里，从他的佣金里分给下级代理的部分。
· 表里还有一列「预付抵(停用)」：早期版本曾用预存余额抵佣金，该功能已停用，只有历史结算单可能带非零旧值，新结算单恒为 0，对不上账时别被它迷惑。

2. 每月流程

  1. 月初生成：在右上生成卡里输入月份（格式 2026-06）→ 点「生成/重算」。系统按订单数据给每个代理各生成一张；重复点是"重算"，但已核准、已支付的结算单不会被覆盖，放心。
  2. 核对：点任意一行打开详情抽屉，逐项看 GMV → 应得佣金 → 分给下级 → 净佣金 → 应付；下方「佣金明细」逐单列出订单号、佣金基数、费率、金额，可以逐笔追查。
  3. 走审批：核对无误 → 「提交审核」；复核人在待审核状态下点「核准」（有问题就「打回草稿」）。
  4. 付款并标记：线下把钱付给代理后，回来点「💰 标记已支付」收尾。付错了还没付？「撤回审核」退回上一步。

六、开票怎么勾（六态开票）

这里的"开票"指的是给航司出票/系统开票的进度标记（不是发票）。每张订单有 三个独立开关：去程、回程、系统，各自可以是"已开/未开"——三个开关 × 两种状态，习惯叫"六态开票"。

订单详情 · 开票区（示意）
去程 已开 回程 未开 系统 已开
去程 / 回程按航段分别开票；翻为「已开」时会校验该班次开票上限。
  • 在哪切换：订单详情里的「开票」区，点开关即改，立即保存。列表页的开票列只能看不能点。
  • 上限校验：把某航段翻成"已开"时，系统会检查该航班班次的开票上限，超限会被拒绝并提示原因——这不是故障，是防超开。
  • 批量打标：订单列表勾选多单后，用「批量开票」下拉一次打标（去程/回程/系统 × 标已开/标未开 共六个选项）；个别订单超上限会单独失败，不影响其他单。
  • 财务用途：对账时用列表的「开票筛选」把"去程已开但没收够钱""回程未开"这类单筛出来核（见下一章）。

  • 开票筛选：筛选区可按"去程/回程/系统 × 已开/未开"组合筛，配合出行日期区间用，比如"本周出发 + 去程未开"。
  • 订单详情里还有两块财务专区：①「预期到账金额」——出纳填这单预计要收的钱，管理员核过后可锁定，锁定后别人改不了；②「订单杂项成本」——导游服务费、赠送费用、手续费、操作费（每单固定 ¥20 系统自动计提，可改可删）、其他，这些会进成本核算。
  • 整单状态"出票完成"≠开票列：前者是订单整体推进阶段，后者是逐航段的开票标记，对账以开票列为准。

八、导出对账用哪张表

订单列表上方有一排导出按钮，财务日常对账认准「📊 导出全岗总表」，其他的了解用途即可。

推荐：📊 导出全岗总表

  • 一行一位乘客的完整台账 xlsx：代理机构、乘客中文名、乘客拼音名、出发(往返)日期、航班号、舱位、结算价格、尾款金额、已到账金额、单房差、签证金额、退款金额、是否清账、开票状态、证件信息、分房情况、订单成本、录入时间/人员等，系统里真实存有的字段全部填满。
  • 金额列全部是每人均摊口径（见第一章）；每人尾款＝(总价＋售后调整−已到账−预存抵扣) ÷ 人数，不会出现负数（多付按 0 算清）。
  • 范围怎么定：按列表上方「出行日期」区间选单（不填＝全部）；如果勾选了订单，就只导勾选的这批。
  • 自动排除：草稿、已取消、支付超时、失败、已退款的订单不进这张表（它们不占座也不计收）。

九、经营报表怎么看

位置：左侧导航 → 财务 → 经营报表（仅管理员）。顶部选日期区间（快捷键：最近 30 天 / 最近 90 天 / 本月），右上「⬇ 导出 xlsx」一键把几张报表打包成一个文件。三个页签：

1. 销售毛利

可按产品线 / 渠道（代理分销·会员直订·游客）/ 销售代理三个维度切换，每行显示订单数、收入、成本、毛利、毛利率和毛利占比条。重点看黄色徽标：

「⚠︎缺 N 项成本」＝这一行有 N 项成本没录，毛利被高估了——先去财务页把成本补上再看数（第十章）

2. 应收账龄——谁欠钱、欠多久

顶部是总应收和四个账龄桶汇总（0–7 天 / 8–30 天 / 31–60 天 / 61 天以上），下方是逐单明细（应收合计 / 已收 / 余额 / 账龄天数 / 所在桶），按欠款金额从大到小排。61 天以上是红色，优先处理。明细最多显示前 500 条，但顶部汇总是全量的。

3. 代理欠款——催款名单直接用这张

按代理汇总：欠款订单数、应收余额、预存余额，欠得多的排前面。看到"应收余额大、预存余额也大"的代理，可以和对方约定用预存余额抵欠款（在订单里逐单抵，见第二章）。

十、财务页：成本必须录，毛利才准

位置：左侧导航 → 财务 → 财务（仅管理员，每次打开记审计日志）。这是最细的成本核算页，五个页签：概览 / 航班毛利 / 订单毛利 / 月度趋势 / 成本维护。

🚨 财务日常最重要的一件事：录成本。成本不录，系统不会报错，毛利会直接虚高——只在报表上给你一个"⚠︎缺 N 项成本"的提示。看到就去补。
  • 成本维护三个入口：①航班成本周期（主用）——按"航班号 × 日期段"录一组成本（包机总价、机场税去/回、燃油、旺季附加、机型调整、起降折扣/机场补贴可为负数），区间内班次自动套用；②单班次覆盖——个别班次特殊价单独录，优先于周期；③产品成本——酒店净房价 / 签证成本 / 车队结算价（日常由操作部在产品管理维护，财务可查）。
  • 只调未来日期段：修改航班成本周期会实时重算覆盖区间的历史毛利，所以过去的日期段不要动，避免历史账面变动。
  • 机票成本口径：包机总成本 ÷ 总座位数，每位乘客摊一个座位；没卖掉的座位摊到的成本单列为"空座沉没"，不摊进客人头上。
  • 两个导出：「⬇ 全量汇总（按乘客）」＝一行一乘客的成本利润明细；「⬇ 按航班分组」＝一行一个班次的整班盈亏（含载客率、空座沉没）。

十一、常见问题 FAQ

导出表里的金额和订单总价对不上？
正常。导出是一行一乘客，所有金额列都是每人均摊（订单金额 ÷ 出行人数）。把同一订单几行加起来才约等于订单总价。见第一章的例子。
票务名单里乘客姓名后面带 MR / MS / MSTR / MISS，和我的底表对不上名字？
那是航司出票要求的称谓后缀（按乘客年龄性别自动加的），只出现在票务出票类表里。财务对人名请用「全岗总表」里专门的「乘客拼音名」（纯拼音，无称谓）和「乘客中文名」两列。
客人说付了钱，订单怎么还显示欠款？
系统不自动到账，客人传了付款截图状态也不会自己变。财务/运营要人工处理：钱能对上订单 → 订单详情「确认收款」；对不上 → 先在收款对账台登记进账，之后再认领。
结算单里「预付抵(停用)」这列怎么有数字？要不要处理？
不用处理。用预存余额抵佣金的老功能已经停用，这列只在历史结算单上留有旧值；新生成的结算单该列恒为 0，应付＝净佣金。
尾款显示蓝色的"多付"，钱要退吗？
不一定退。两个去处：代理订单可「存入代理余额」留着下次抵扣；说不清归属就「转挂账池」，之后在收款对账台认领到别的订单或走退款。见第二章第 3 节。
月结代理一堆订单欠尾款，要逐单催吗？
不用。月结代理的欠款显示为蓝色「月结挂账」，月底统一对账收款。真正要催的是琥珀色"欠款"的单（逐单到账代理和散客）。
报表毛利看着高得不对劲？
先看行末有没有黄色「⚠︎缺 N 项成本」——缺成本时毛利是被高估的。去财务页 → 成本维护把航班/产品成本补齐再看。另外仪表盘首页的"今日营收"是当日订单额（GMV）口径，和财务页的核算口径本来就不是一回事，别拿它们互相对。
对账台里点了"退款"的钱还能再认领吗？
不能，退款是终点站。所以退款前必须填备注、系统还会弹窗二次确认。点错了请联系管理员按审计日志核实处理。
导出全岗总表里怎么少了几张订单？
两个常见原因：①草稿/已取消/支付超时/失败/已退款的订单不进该表；②该表按出行日期区间选单，你可能想找的是按下单时间录入的单——换「📥 导出 CSV / 📤 导出」按下单时间导。另外如果列表里勾选了订单，导出只含勾选的那批。
开票开关怎么翻不过去？
每个航班班次设有开票上限，把航段翻成"已开"时超限会被系统拒绝并提示，防止超开。找票务岗/管理员确认该班次的上限设置。
手动调余额 / 改数据出了错，找谁查？
系统 → 审计日志。谁在什么时间从哪个 IP 做了什么（收款、余额调整、财务查看、删单……）全部留痕，可看逐字段改动前后对比。余额手动调整、认款确认都在里面。
