开账号自助指引

一人一号 · 实名 · 按岗位配可见范围 —— 2026-08-25

本手册解决什么

  1. 开内部账号（录单专员这类，看得到全部订单）管理员操作
  2. 开代理端账号（天福 / 天盈这类）运营自己就能开
  3. 停用离职账号 / 重置忘记的密码管理员操作
  4. 常见疑问
一句话结论：这三件事后台都有现成入口，不用等开发排期。内部账号找管理员开，代理账号运营自己就能开。
开号前先记住一条：账号按人开，不按岗位开。没有「录单专员账号」这种东西——只有「王小美的账号，她的岗位是通用运营」。岗位是账号上的一个属性，随时可改；名字是谁就是谁，一人一个，不共用。

1开内部账号

适用：录单、票务、签证、房控、财务等公司内部同事。一位同事一个账号。

谁能开：只有管理员账号能开内部账号。目前公司里持有管理员权限的是总经理与副总两个账号。需要开号 / 停号 / 重置密码，找他们其中一位即可，不必联系技术。

入口在哪

左侧菜单最下方 系统 → 账号管理。这一栏只有管理员登录时才会显示，用运营号登录是看不到的——看不到不是坏了，是权限如此。

图 1 · 账号管理页：上半部分建号，下半部分是现有账号清单

怎么给一位新同事开号

下面以「新来的录单同事王小美」为例。注意这个号叫王小美，不叫「录单专员」——「录单专员」是她的岗位，不是她的账号名。

  1. 邮箱——一人一个，建议用公司域名邮箱（如 wangxiaomei@citurtravel.com），这就是她登录用的账号名。
  2. 显示名——填本人真实姓名，例如「王小美」。这个名字会直接出现在订单的「录单人」上，也是导出表里「录入人员」那一列的内容。填成「录单专员」的话，她录的每一单在导出表里都写着「录单专员」——等于什么都没记，将来对账查不到人。
  3. 角色——选 STAFF（列表里显示为「运营」）。ADMIN 是管理员，能停别人的号、改佣金费率，除非确实要给管理权限，否则不要选。
  4. 岗位——保持「通用运营（全模板）」不要动。这是关键一步：通用运营看得到全部订单、余位、全部导出模板；一旦选了「票务岗 / 签证岗 / 房控岗」，导出模板会按岗位裁剪，反而看不全。
  5. 初始密码——点「随机生成」，或自己填一个 8 位以上的。
  6. 点 创建账号，把邮箱和这个初始密码单独发给本人，不要发在群里。
图 2 · 正确填法：显示名 = 本人实名，角色 STAFF，岗位保持「通用运营（全模板）」
初始密码不用担心泄露：本人第一次登录时，系统会强制他先改密码才能进系统。改完之后这个密码就作废了，只有他自己知道新密码——你不需要、也无法再看到。
岗位选错的后果：「录单专员要能看所有单、包括余位」——对应的就是岗位留空（通用运营）。如果手滑选了票务岗，他导出名单时会发现少了列，回头又来报障。建完可以在下方清单里核对一眼那一行的岗位。

「录单专员要开个账号」该怎么翻译

业务上说的岗位名，落到系统里要拆成两件事——谁（账号）和能看到什么（岗位）：

业务上的说法系统里怎么落
「开个录单专员，能看所有单含余位」给那位同事本人开一个实名号，岗位留「通用运营」
「录单的有两个人」开两个实名号，岗位都留「通用运营」
「他调去做票务了」不用新建号，把他那行的「岗位」下拉改成票务岗
「录单专员离职了，新人接手」停用离职那位的号，给新人开新号。不要把老号改个名给新人用——改名之后，老号历史上录的单会全部显示成新人的名字，账就串了
不要开岗位共用号。系统里现存的「运营录单01 / 运营录单02」是上线初期的过渡账号，正在逐步停用，不要照着它们再开新的。共用号一旦出事——改错状态、删错单、金额录错——审计日志里只查得到那个共用号，查不到具体是谁操作的，责任无从落实。

2开代理端账号

适用：天福、天盈这类外部代理机构，要给他们一个能自己录单的登录号。

这个不用找管理员——运营账号自己就能建。入口：左侧菜单 客户 → 代理管理 → 右上角 ＋ 新建代理。
图 3 · 新建代理表单：登录邮箱与初始密码就在表单里，建完即是一个可登录的代理账号
  1. 上级代理——通常不选，就是建一个 1 级代理。只有在建某家代理的下级时才需要选。
  2. 登录邮箱 + 初始密码——这两项就是代理登录用的账号密码，建完直接给对方。
  3. 显示昵称 / 公司名 / 联系人 / 联系电话——按实际填，昵称会显示在订单的归属代理上。
  4. 点 创建代理。
图 4 · 填好的样子（示例数据）

「只能看自己的单」不用额外配置

代理账号天生就只看得到自己家的单——别家代理的订单在他的列表里根本不会出现，这是系统底层隔离的，不是靠勾选项控制的，也没法被误操作打开。所以「只能看自己的单子，其余代理单不可看」这条要求，建完号就已经满足了。

代理号是「机构号」，不套用一人一号。代理账号代表的是天福、天盈这一家公司，不是某个人，所以显示昵称填公司名或「天福-录单」这类都可以。订单上记的归属代理也是公司，不是个人。
一个代理机构 = 一个登录账号。目前系统里一家代理只能有一个登录号。如果需求是「天福已经有账号了，还要再给他们家员工单开一个只录单的子账号」，这个现在做不到，属于新功能，需要单独提出来排期。请先确认是哪一种情况。

3停用账号 / 重置密码

同事离职、或者密码忘了，都在「账号管理」页那张清单上直接操作（管理员权限）。

场景操作结果
同事离职该行点 停用立即无法登录；已登录的会话也会当场失效。历史订单上他的名字保留，账不会乱
忘记密码该行点 重置密码，设一个临时密码给他他用临时密码登录后，系统强制他改成自己的新密码
调岗该行「岗位」下拉直接改即时生效，不用重新建号
不要为了省事共用账号。共用号一旦出问题（改错状态、删错单），审计日志里只能查到那个共用号，查不到具体是谁。这也是我们把原来几个共享号封存、改成一人一号的原因。

4常见疑问

Q：我用自己的运营号登录，左边没有「账号管理」这一栏。
A：正常。这一栏只对管理员显示。开号找总经理或副总。
Q：新建账号那里「角色」为什么是英文 STAFF / ADMIN？
A：这是显示上的历史遗留，STAFF = 运营，ADMIN = 管理员，列表里显示的就是中文。选 STAFF 即可。
Q：录单专员要能看到余位，需要单独开权限吗？
A：不需要。岗位保持「通用运营」，余位、订单、导出模板全都看得到。
Q：代理账号能不能限制成「只能录单，别的都不能点」？
A：目前不能。代理端除了录单，还能看自己的订单、查预付余额、提充值申请——这些是代理端本来的功能，没有细到单项的开关。如果确实需要「纯录单」的受限账号，请单独提需求。
Q：能不能就开一个「录单专员」账号，几个录单的同事一起用？
A：不要。订单上的「录单人」和导出表的「录入人员」记的就是账号显示名，共用号会让这两处全部变成同一个名字，出错时查不到人。开号是免费的，有几个人开几个号。
Q：同事离职，他的号能不能改个名字给新人接着用？
A：不能。显示名一改，他历史上录过的所有订单，「录单人」都会跟着变成新人的名字，历史记录就被篡改了。正确做法：停用旧号 + 给新人开新号。
Q：初始密码设简单点行不行？
A：至少 8 位。反正对方首次登录必须改密，简单的初始密码活不过一次登录，不必纠结。
