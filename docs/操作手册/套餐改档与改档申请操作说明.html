套餐改档与代理改档申请 操作说明

一、谁能做什么

账号能做什么
运营 / 管理员在订单详情里直接改档，当场生效；处理代理提的改档申请（确认或驳回）
代理只能对自己名下的订单提「改档申请」，提了不生效，等运营确认
改档会动两样东西：钱（按新档重算，差额记成一条调价）和房（换到另一个档次的房池）。所以代理提的申请，运营确认之前订单一分钱一间房都不会变。

二、运营：直接给订单改档

解决了什么：以前「套餐改档」按钮藏在「金额明细（点开）」里面，不好找。现在订单详情「产品内容」标题右边就有。

怎么操作

  1. 打开订单详情，「产品内容」标题右边点「套餐改档」。
  2. 弹窗里选要改到哪一档（只列在售的套餐，当前这档不会出现）。
  3. 原因选填，会进审计和差额行。
  4. 点「确认改档」。

产品内容标题右边的「套餐改档」按钮

选目标套餐，填原因

改完会告诉你差额是多少、有没有要人工跟进的

「金额明细」里套餐那一行的「套餐改档」按钮还在，两个入口是同一个功能。

三、代理：提改档申请

解决了什么：代理以前没有任何入口，只能微信找运营。现在代理在订单详情里自己提，运营在系统里看到就能处理。

怎么操作（代理账号）

  1. 打开自己的订单，「产品内容」标题右边点「申请改档」，页面会跳到下面的「改档申请」区块。
  2. 选想换成哪一档，备注写清楚原因（比如「客人想升到四星」）。
  3. 点「提交改档申请」。

代理账号看到的是「申请改档」，点了跳到下面的区块

代理端的改档申请区块：选目标套餐，写备注，提交

提交后显示「待确认」，运营处理后这里会变成已确认或已驳回，驳回原因也在这

一张单同时只能有一条待确认的申请，运营处理完才能再提。提交之后订单本身不会有任何变化。

四、运营：处理代理的改档申请

两个地方都能处理，跟议价申请一样。

订单列表上方的「改档申请」队列

按钮上的橙色数字是待处理条数。点开是队列，每行写着哪张单、哪个代理、从哪档改到哪档，能直接确认或驳回。

列表上方的入口，带待处理数

待处理队列

订单详情里的「改档申请」卡片

黄色卡片就是待处理的，下面可以写备注再确认或驳回

确认后当场执行改档，差额和提醒都显示出来

点什么发生什么
确认改档系统立刻按目标套餐重新计价并换档，差额记成一条调价行，代理那边看到「已确认」
驳回订单不变，申请标为已驳回，写的原因代理能看到
确认那一刻才算钱，用的是当时的应收和当天的结算价，不是代理提申请时的。中间加过的改期费、房差不会被抹掉。

五、2晚改3晚这种晚数有变化的

改档能处理晚数变化：选「三星 4天3晚」这种目标套餐，酒店离店日会按新晚数自动往后推。但回程航班不会自动改。

  1. 先改档（或先确认代理的改档申请）。
  2. 再到「金额明细」里回程航班那一行点「改期」，把回程挪到新的日期。

晚数有变化时，确认结果里会提醒回程要另行改期

顺序是先改档再改回程。只改回程不会再动酒店日期，不会重复平移。

六、改完之后钱和房怎么算

订单应收按新档重算，「新应收 − 原应收」记成一条调价行，正数补收、负数减少
已收的钱不动。尾款或多付按新应收自然浮动，多付的到付款情况里处理
代理单结算价按目标档次和出发日在结算价日历里重新取价，立减规则照常生效
酒店换到目标档次的随机池，离店日按新晚数重算；原来指定的酒店会被清除，需要的话重新指定
机票、签证、接送全部不动
审计谁提的申请、谁确认的、改前改后是哪档、差额多少，全部有记录

七、点不了的几种情况

情况怎么办
酒店已经落位到具体酒店（不是「X星随机」）先用「换酒店」把住宿处理掉，再改档
订单已取消 / 已退款 / 超时不能改档
目标套餐已下架换一个在售的档次
一张单里有多条套餐行联系技术处理
已经有一条待确认的申请先处理掉那条
代理单改档之后应收变了，佣金不会自动重算，需要财务手工处理，和改期、取消航段是一样的口径。
