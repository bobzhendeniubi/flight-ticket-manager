四、订单状态：每个状态什么意思、什么时候点什么

一张单的正常一生是这样走的：

草稿→ 待支付→ 已支付→ 处理中→ 已出票→ 已完成

旁边还有几条「岔路」：

已取消支付超时退款申请中已退款改期申请中已改期出票失败
状态什么意思轮到你做什么
待支付单建好了，钱还没到收到钱后在详情里点 确认收款（见第五章），再点 标记已支付
已支付钱齐了点 进入处理，交给出票/订房流程（工单也会自动生成）
处理中票务/酒店/签证在办办妥后点 出票完成；办砸了点 出票失败
已出票出行凭证都齐了客人回来、无售后，点 订单完结 收尾
退款申请中客人在前台申请了退款核实后二选一：同意退款 或 驳回退款（回退处理）
改期申请中客人在前台申请了改期联系客人确认新班次 → 做改期（见第六章）→ 标记已改期；不同意就 驳回改期（回退出票）
出票失败没出成票解决问题后点 重新处理，或走退款
已取消 / 支付超时单子作废，座位已释放一般不用管；要复活找管理员（见下方提醒）

在哪点：打开订单详情，顶部只会出现当前状态允许走的那几个按钮——不用背整张状态表，看见什么按钮就是能点什么。

两个要命的点：① 管理员有「强制改状态」权限，把已取消的单强拉回来会重新占座，拉之前先确认那个班次还有位；② 状态只是「标签」，收钱是收钱、改状态是改状态，先收钱再改状态，别反过来。

六、改签（改期）与换人

6.1 改期（换班次 / 换日期 / 换舱位）

  1. 打开订单详情，找到机票那一行，点行上的 改期。
  2. 选新的班次（可换日期、换舱位）。
  3. 要收改期费就填「改期费（¥）」，不收留空；备注里写清原因（如：客户主动改期 / 航变）。
  4. 点 确认改期。座位会自动从旧班次挪到新班次；新班次卖满了会被系统拒绝，先换个班次再试。改期费会自动记进订单尾款，记得按第五章收钱。
客人自己在前台申请的改期，订单会变成「改期申请中」，提醒中心也会有待办——你先联系客人确认好新班次，再按上面步骤操作，最后点「标记已改期」。

6.2 换人 / 改出行人信息

  1. 订单详情 → 乘客区 → 点该乘客的 换人/编辑。
  2. 只是改错别字、补生日：直接改完保存即可。
  3. 换成另一个人（证件号变了）：系统会弹确认——原来那个人的护照照片、签发地、有效期、签证号等会被清空重来，只留你这次填的新信息。看清楚再点确认。
  4. 要收换人费就填「换人费（¥）」，会记进订单尾款。
  5. 如果这单已经开过票 / 办过签证，按提示勾选「重置开票 / 签证」，让票务岗、签证岗重新跟进新乘客。
换人是「真换一个人」的大动作，会记入系统操作记录。拿不准就先问带教同事，别硬点。

七、备注四栏怎么用

订单详情里有一块「签证状态 / 备注」。别把所有事都堆在一个框里——按栏分开写，签证岗、财务、操作部各看各的栏，才不会漏。

三条铁规则，导错表基本都是栽在这

  1. 勾选优先：只要你在列表里勾选了订单，「📤 导出」「📊 全岗总表」「🎫 票务开票导出」就只导勾选的这些单，上面的筛选和日期全部不生效。页面会有提示条「已勾选 N 条」。想按筛选导，先把勾选取消掉。
  2. 日期口径别选错：「📤 导出」看的是下单时间，「📊 全岗总表」看的是出行日期。想导「8 月出发的客人名单」却去设「下单时间 8 月」，出来的表肯定不对。
  3. 名单类导出不看列表的状态筛选：为了名单齐全，导出会覆盖所有还占着座位的单（包括还没付款的）；而草稿、已取消、支付超时、已退款、出票失败的单不会出现在导出里。列表里筛了「已支付」再导，导出的份数和列表对不上是正常的。
《全岗可用》表里有几列（飞行次数、单房差、抵扣人员等）经常是空的——那是照着旧手工台账搬过来的占位列，系统没有的数据宁可留空也不乱填。日常对账建议直接用「📊 导出全岗总表」，它把系统里真实有的字段全填满了。另外全岗总表里的金额是按每位出行人均摊的，几个人的单每行只显示他那一份，别当成每人都付了全款。

九、删单与回收站

删单

  1. 打开订单详情，最底部有「删除订单」。删除是软删除：单子从列表、导出、统计里消失，但数据还在，可以恢复。
  2. 两种单删不掉，系统会拦：①还占着座位的单——先把订单取消（释放座位）再删；②收过钱还没退完的单——先把退款处理完。

回收站（仅管理员能看）

  1. 订单页顶部点 🗑 回收站，弹窗列出所有已删除订单，可按订单号 / 联系人 / 乘客姓名搜。
  2. 点某单的「恢复」→ 单子回到删除前的状态，重新出现在列表、导出和统计里。恢复不影响座位账。
  3. 误删了单又不是管理员？找管理员帮你从回收站捞回来。

10.3 顺带认识：产品管理（产品 → 产品）

录单时下拉里能选到的酒店、车、签证、套餐，都是在这一页维护的。四个页签：酒店 / 接送（车型）/ 签证 / 套餐，各自有「＋ 新增 / 编辑 / 删除」。要点三条：

  • 删除 = 下架，不是抹掉——历史订单完全不受影响，只是以后录单选不到它了。
  • 套餐向导：把机票+酒店+接送+签证组合起来卖。定价时填「想卖的价」，系统自动换算成整单折扣；机票部分随出发日浮动，所以不同出发日的套餐最终价会不一样，这是正常的。
  • 套餐可设停售日和团期。改产品价格会立即影响新录的单，改之前跟管理员打个招呼。

十一、常见问题 FAQ

导出的《全岗可用》表里，「飞行次数」「单房差」这些列怎么是空的？表坏了吗？
没坏。《全岗可用》是照旧手工台账原样复刻的，有些列系统暂时没有对应数据，宁可留空也不编数，属于占位列。日常对账请改用「📊 导出全岗总表」，那张表把系统真实有的字段全填满了。
我明明设了日期筛选，导出的单子却不是那批？
九成是勾选没取消。只要列表里勾了单，三个导出按钮都只导勾选的那些，日期和筛选全部失效——看一眼有没有「已勾选 N 条」的提示条。另外注意口径：「📤 导出」按下单时间，「📊 全岗总表」按出行日期，别用错。
列表筛了「已支付」，导出来的却混着没付款的单？
正常。名单类导出为保证名单完整，覆盖所有还占座位的单（含未付款的），且自动排除草稿/已取消/超时/已退款/出票失败——它不吃列表的「状态」筛选。
全岗总表里的金额，跟订单总价对不上？
那张表一行是一位乘客，金额（结算、到账、尾款、单房差、退款等）都是按人头均摊后的数。一单 3 个人，每行只显示三分之一，加起来才是整单。
全岗总表的「飞行次数」有的有数有的空，同一单还不一样？
它是「这位客人历史上跟我们飞过几次」，按证件号从老客档案里查的——同单不同人当然不一样；新客或证件号对不上档案就是空。它不是本单的航段数。
客人说付了钱，订单怎么还是「待支付」？
到账全靠人工确认，系统不会自动变。核对到账后要你在详情里点「确认收款」，再点「标记已支付」。客人自己在前台传的付款凭证，会进财务的「收款对账台」等认领——拿不准就问财务这笔认了没有。
「删除订单」点了没反应 / 报错？
还占座位的单不能删，先取消订单（释放座位）再删；收过钱没退完的也不能删，先处理退款。删掉的单进回收站，管理员能恢复。
改期为什么被拒绝了？
新班次卖满了。换个班次或日期再试；确实要挤进满班找管理员处理。
提醒中心一条都没有？
要先点「⚡ 生成今日提醒」才会扫描生成。它只在有人点的时候跑一次，每天上班点一下就好；重复点不会生成重复条目。
月结代理的单一直挂着尾款，要不要催？
不用。月结代理的单显示蓝色「月结挂账」是正常状态，月末财务统一对账收款。要催的是琥珀色「欠款」的单。
批量创单为什么有几单失败了？
批量是逐人建单，个别失败（最常见是班次卖满、生日格式不对）不影响其他人。看弹窗里逐条的失败原因，改好后把失败那几个人再建一次即可。
备注写了怎么客人看到了？
「客户备注」这一栏客人在前台是能看到的——内部话请写「内部备注」（琥珀色那个框）或四栏里，客人和代理都看不到。
