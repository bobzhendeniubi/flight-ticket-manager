左侧导航点「航班」。这一页管所有自营航线：每条航线一张卡片，卡片里能翻看它的全部班次（班期）。

展开后默认是📅 月历视图：一天一格，一眼看整月的余位和价格；也可以切到📋 列表视图（可按月份或具体日期筛）。

  • 余位数字：绿=充足，黄=偏紧，红=紧张（按占容量比例判断）。
  • 价格：只统计"在售"班次的经济舱现价；多班在售显示最低～最高。

▲ 重点：「导出整班订单」= 该班次全部订单明细 xlsx；「导出整班·全岗」= 该班次的全岗名单（一行一乘客，带金额与票务/签证列）。核对某个班次名单时用它们最快。
  • 售罄 vs 已下架，是两回事：「售罄」是余位卖完系统自动显示的，没有开关；「已下架」是人工点"下架"收起来的，前台买不到，调完价可"重新上架"。两个徽章可能同时出现。

  • 改容量/价格后，前台余位显示立即跟着变。

三、切位（包位）：现在只能看和回收

左侧导航点「切位」。切位是把某班次的一部分座位"份额"锁给某个代理去卖，到期没卖完的座位收回来。

⚠ 重要：新建切位目前已暂停。页面顶部有一条琥珀色提示——因为切位暂时没有真正锁住公共库存，切给代理的座位散客照样能买走。所以「+ 新建切位」和「📦 批量切位」两个按钮是灰的点不了，现阶段这一页只做两件事：查看存量切位、把过期的收回来。等系统补齐库存联动后才会重新放开新建。

四、订单页的票务视角：哪些单该出票

左侧导航点「订单」。订单从建立到收尾的状态流是：

图 4-1 · 订单状态流（票务岗盯中间三步）
草稿→待付款→已付款→处理中→出票完成→已完成

旁路状态：已取消 / 支付超时 / 退款申请中 / 已退款 / 改签申请中 / 已改签 / 出票失败

▲ 票务岗的口径：「已付款」「处理中」的含机票订单 = 该出票的单。在开票系统出完票后回来做两件事：① 把该单的开票开关翻"已开"（见第五节）；② 整单出完后把状态点成「出票完成」。

4.1 怎么把该出票的单筛出来

图 4-2 · 筛选区（票务岗常用的四个筛选已高亮）

▲ 最常用的组合：「出行日期 = 某一天」+「开票筛选 = 去程未开」→ 这天该出票还没出的单全出来了。选完日期点日期框下面的小字「只看某一天」，就是只看当天。

五、六态开票：去程 / 回程 / 系统 怎么勾

每张订单有三个互相独立的开票开关：去程、回程、系统。每个开关有"已开 / 未开"两种状态，所以叫"六态"。出一段票就翻一段的开关，实事求是。

5.1 在订单详情里翻开关

在订单列表点开要操作的订单，详情抽屉里靠上的位置有「开票」区。
出完哪一段的票，就点哪一段的按钮：去程出了点「去程」、回程出了点「回程」。「系统」开关表示在开票系统里的整体开票动作，按你们的对账口径勾。
点一下 = 翻转一次（未开→已开，或已开→未开）。点错了再点一下就翻回去。
图 5-1 · 详情抽屉「开票」区（往返订单显示三个开关；单程只有去程+系统）
开票
去程：已开 回程：未开 系统：未开

去程 / 回程按航段分别开票；翻为「已开」时会校验该班次开票上限。

5.2 去程 / 回程是怎么认定的？

不用你判断——系统把订单里的机票段按出发时间先后排序：飞得早的那段是去程，第二段是回程。只有一段机票就是单程，只显示去程开关。

5.3 翻"已开"时系统会把三道关

拦截情形系统提示的意思你该怎么办
超班次开票上限「该班次已开票 N 张，座位库存共 M 张，无法继续开票」。上限 = 该班次各舱位容量之和（商务+经济），等于这班机真实能卖的座位数。先核对是不是重复标了；确实要放宽找管理员调该班次的舱位容量。
订单已取消 / 已退款 / 支付超时 / 草稿这种状态的单不占开票额度，也不允许标开票，避免账目失真。如确需开票，先让运营把订单恢复到有效状态（如已付款/处理中）。
订单在回收站（已删除）回收站里的单不能标开票。找管理员先「恢复」订单。
上限计数的两个贴心口径（不用你操作，系统自动算）：① 婴儿票"有票无座"，不占开票额度；② 同一位客人（同一个证件号）在同一班次上有两张单，也只占 1 个座，不会重复扣额度。翻回"未开"永远不拦——纠错随时可以。

5.4 批量开票：一次给一批单打标记

图 5-2 · 勾选多单后出现的批量工具条（右侧「批量开票」）
已选 12 条订单| 批量开票：去程标已开 ▾ 应用到 12 条
▲ 下拉有六个选项：去程标已开 / 去程标未开 / 回程标已开 / 回程标未开 / 系统标已开 / 系统标未开。逐单执行，某一单超上限只有它自己失败（失败原因会列出来），其他单照常成功。

六、改期（改签）单怎么处理

客人在前台申请改签后，订单状态会变成「改签申请中」（提醒中心也会出现对应待办）。票务岗联系确认后，在订单详情里实际执行改期。

在订单列表用状态筛「改签申请中」找到单子，点开详情。
找到「产品内容」（套餐单点开「金额明细」折叠区），在机票行右侧点「改期」。
在改期表单里依次选：航班 → 新班次 → 新舱位（不换就选"沿用原舱位"）；要收改期费就填金额（会自动计入订单尾款），可加备注（如"客户主动改期 / 航变"）。
点「确认改期」。座位会自动从原班次挪到新班次；新班次售罄会被系统拒绝，需另选班次。
改完后把订单状态点成「标记已改签」；如果和客人确认不改了，点「驳回改签（回退出票）」把状态退回去。

  • 航变（航司改班）导致换过班次的机票行，会带一个红色「✈ 航变」小标，鼠标悬上去能看到"原班次 → 新班次"。
  • 改期后如果票要重出：先把老票对应的开票开关翻回"未开"，出完新票再翻"已开"，账才对得上。
  • 换乘机人（详情里编辑出行人）时，表单里有「重置开票状态（开票 → 未开）」勾选项——换了人票作废重出的，记得勾上。

七、去程 no-show 与回程释放 / 恢复

航司每天会发一份 no-show 名单：客人没登机。这跟客人自己决定不飞、要退钱是两回事——那种走「取消航段」，退钱、扣手续费、放出去的座位不能再要回来。no-show 是钱和成本一分不动：去程给客人打个 no-show 标，回程座位可以先放出去卖；代理来说要保留回程，还能恢复回来。本节说的就是这一套。

两条路别选错：no-show = 客人没登机，钱不动、回程能恢复；取消航段 = 客人主动不飞要退钱，退钱之后座位放出去就抢不回来了。本节末尾有对照表。

7.1 入口在哪

  • 订单详情页里（运营工具附近）有个「no-show 处理」按钮——本单有去程航段、还没标过 no-show 才会出现。
  • 标过去程 no-show 之后，只要回程座位还在（没释放过，或者释放后又恢复回来），这个入口不会消失，只是换个文案继续留在原地：只标了 no-show、当时没勾「同时释放回程」的单，按钮变成「释放回程座位」，之后随时能从这个按钮把回程放出去；标过 no-show、回程释放过又恢复回来的单，按钮变成「再次释放回程」（代理又不要回程了，再放一次）。回程一旦被释放或作废（不可再恢复），入口才会收起。
  • 回程那一行旁边有「恢复回程」按钮——只有回程座位处于「已释放」状态时才会出现。

7.2 标记 no-show + 释放回程：怎么操作

打开订单详情，点「no-show 处理」。
面板顶部勾选这次要标记的乘客，默认全选＝整单处理。只勾部分人：系统会先按你勾的人自动拆出一张新单（票随人走），再对新单标记——套餐单目前拆不了单，只能整单处理，勾部分人会被挡下来。
勾选「同时释放回程座位」（默认勾选）。只想记一笔去程 no-show、暂时不放回程座位，就取消这个勾——不影响以后再放，回来时同一个入口会变成「释放回程座位」按钮，直接点它继续释放即可，不用重新勾人。
可以填一句备注（比如航司名单的日期、核对来源）。
点确认，再确认一次就生效。

7.3 面板打不开 / 点了没反应？预检拦截的几种情况

点开面板会先自动预检，不满足的条件会逐条列在面板上，人话版对照：

面板上写的原因意思 / 怎么办
订单在回收站这单已被软删，先在回收站把它恢复出来再操作。
订单当前状态不是占座中已取消 / 已退款 / 支付超时的单不再占着座位，标 no-show 没有意义。
本单没有可标记的去程航段去程没录班次，或者去程航段已经被取消 / 释放掉了。
本单有 3 段以上航段系统只认「去程 + 回程」两段，段数更多时猜不出方向，人工逐段处理或先拆单。
去程航班还没起飞没飞就不算 no-show；客人是临时不想飞了，走「取消航段」。
回程航班已经起飞（且勾了「同时释放回程」）起飞后的座位放不回库存了，取消勾选「同时释放回程」，改成只记一笔去程 no-show。
有进行中的退款先把退款流程走完或驳回，再来标 no-show。
回程座位当前已经是释放状态不能重复释放；要把座位收回来重占，去回程行点「恢复回程」。

7.4 回程已经出票，释放座位后会怎样

  • 座位当场放回库存可以重新卖，钱一分不动，票本身系统不会帮你作废或申请退票。
  • 如果回程有确认出票记录，系统会自动生成一条「撤名单/退票」工单（在待办/工单看板里能看到，标题带订单号和航段方向），提醒票务去航司渠道办撤名单或办退票，办完在工单里标记已处理。
  • 如果回程还没出票，对应的开票任务会被系统直接标记取消，不会生成工单。
  • 如果回程当时已经标记「已开票」，释放座位会顺带把这个开票位清成「未开」（钱和已开的发票本身不受影响）；之后如果恢复回程并重新出票，记得票务台把开票开关重新翻一次。

7.5 恢复回程：余位够不够、超售怎么确认

回程行点「恢复回程」，面板先做预检：原班次现在还有几座余位。
有余位：直接占回原班次、原舱位（含当初升舱拆分的座位，也是原样占回），点确认即可。
没余位：不是勾选框，而是弹一个红色二次确认框，按钮文案会写清楚这次还要再超几座（比如「确认再超 2 座并恢复」）。面板会显示「该班已超售 A 座，本次再超 k 座，恢复后累计 N 座（上限 M 座）」——上限按这个班次累计算，不是单看这一次。点了按钮才真正超售，系统按关键审计记这一笔，超过上限会直接拒绝，不能无限超下去。

7.6 再次释放

回程恢复回去之后，代理又说不要了——这种情况很常见。此时订单详情的入口按钮会自动变成「再次释放回程」，不用重新勾人，直接对回程再放一次座位。去程最初标记 no-show 的时间和操作人不会被覆盖，系统只会在历史记录里追加这一次释放的记录，方便事后核对总共释放过几次。

7.7 客人要换到别的日期飞，怎么办

no-show 处理和恢复回程都不涉及换班次。客人如果不是不来了，而是要换到别的日期，按第六节的「改期」流程走，改期费按政策收取，跟本节无关。

十、常见问题 FAQ

Q1：乘客姓名后面的 MR / MS / MSTR / MISS 是哪来的？能改吗？
航司要求的称谓，系统按"出发日 − 出生日期"的实足年龄自动派生：成人男 MR、成人女 MS、儿童/婴儿男 MSTR、女 MISS（详见第八节表格）。一般不用改；个别乘客有特殊要求时，在订单里手工录入称谓，导出会优先用手录的。
Q2：点"已开"报错「无法继续开票」怎么办？
说明这个班次按航段统计的已开票座位数已达上限。上限不是拍脑袋的数字，就是这个班次各舱位容量之和（能卖多少座就能开多少票）。先核对是否重复标记；确实要放宽，请管理员调整该班次的舱位容量。另外婴儿不占额度、同一证件号跨订单只占一个座——这些系统都自动处理了。
Q3：已取消的订单为什么不让标开票？
已取消 / 已退款 / 支付超时 / 草稿以及回收站里的订单不占班次开票额度，标了标记也不计数，只会让导出和财务的账变乱，所以系统直接拦住。确需开票，先让运营把订单恢复到有效状态（如已付款/处理中）。反过来，把"已开"翻回"未开"任何时候都不拦。
Q4：「售罄」和「已下架」有什么区别？
「售罄」是余位卖完系统自动显示的，没有任何开关；「已下架」是人工把班次收起来（前台不可售），调完价可以"重新上架"。一个班次可能又售罄又被下架，两个徽章同时出现是正常的。
Q5：切位页的「新建切位」按钮为什么是灰的？
故意的，不是坏了。切位暂时没有真正锁住公共库存（切给代理的座散客照样能买），为避免超卖已暂停新建。现阶段这一页只用来查看存量和回收过期切位，请勿把切位余量当成可承诺的库存。
Q6：批量改状态里为什么没有「出票完成」？
故意的。批量场景只放开"去程/回程/系统标已开（未开）"这类航段级标记（用旁边的「批量开票」下拉）；整单"出票完成"是终态，请逐单进详情确认后再点，防止把没出完票的单一起标成完成。
Q7：导出的《票务专用》表里为什么少了几张单？
三种正常情况：① 该模板只导含机票的订单，纯酒店/纯签证单不进表；② 已取消/已退款/支付超时/出票失败/草稿的订单一律不导；③ 列表里勾选了订单时，导出只包含勾选的那几条（提示条会写明），取消勾选即恢复按筛选导出。
Q8：改期后座位和票怎么处理？
在详情的机票行点「改期」选新班次确认后，座位自动从原班次挪到新班次（新班次售罄会被拒）；改期费填了会计入订单尾款。票要重出的：先把原航段开票开关翻回"未开"，新票出完再翻"已开"。最后记得把订单状态点成「标记已改签」。
Q9：我看不到"改价 / 新班次 / 保存价格"这些按钮？
这些操作只对管理员账号开放，票务岗账号看不到是权限设计，不是故障。需要调价、改容量、加班次时，把班次和目标价报给管理员处理；改完立即生效，前台余位显示实时更新。
Q10：座位统计的"余票"和前台客人看到的一样吗？
同一套数字：余票 = 容量 − 已售 − 锁位。区别只在展示方式——后台给你看精确张数，前台对客人只显示"充足/紧张/少量"这类档位，不露具体数字。余票少于 20 会标红 🔴，看到红的及时关注。
Q11：每天下班前，票务岗要核对什么？
用「🎫 票务开票导出」把当天/近几天出发的"未开"单导出来过一遍：该出的票是否都出了、开关是否都翻了；再瞄一眼各班次开票数有没有贴近上限的异常。工单看板上"出票"类的红卡（出发 48 小时内未完成）必须当天清零。
