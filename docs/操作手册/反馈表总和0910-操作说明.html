一、批量创单：名单里每个人可以单独填结算价

解决了什么：批量创单以前只有整批一个「结算价/人」，同一批里有人谈的价不一样就得分两批录。现在乘客名单表最右边多了一列「结算价/人（¥）」，谁的价不一样就在谁那一行填。

怎么操作

  1. 订单管理 → 「批量创单」，产品类型选单程或往返机票（套餐批量没有这一列，套餐价由系统按结算价日历算）。
  2. 名单表往右拉到最后一列「结算价/人（¥）」，只给价不一样的人填；其他人留空。
  3. 下面「旅游团」块里的整批「结算价/人」照旧：留空的人按它走；整批也留空就按结算价日历 / 系统价。
  4. 底部会提示「名单里有 N 位填了自己的结算价」，核对一下人数再点「批量创建」。

名单表最右一列「结算价/人（¥）」，留空 = 按整批结算价

填了之后底部有提示：几位按本人的价成交，其余按整批口径

价格怎么算

优先级本人填的 > 整批填的 > 都留空（结算价日历 / 系统动态价）
填的是什么价每位出行人的整程价，往返单系统会自动按去程/回程分摊，不会收两遍
订单里怎么显示和整批结算价一样：机票行价格来源标「团队议价」，订单详情能看到本人价和分摊
谁能填运营 / 管理员。代理自助批量录单看不到这一列
「结算价/人」和 OTA 线上单的「结算单价」、「优惠」是二选一的，填了任何一个人的结算价就不能再填 OTA 结算单价或优惠，提交时会拦下来并说明。

二、撤销收款：自己录的、财务还没核实的，自己能撤

解决了什么：9 月 6 日起撤销收款只有财务岗能点，运营录错一笔金额也得找财务。现在改成：谁录的款，在财务核实之前自己可以撤销，撤了重新录就行；财务已经核实过的那笔，还是只有财务能动。

规则一句话

你是这笔款能不能撤
财务岗 / 管理员任何一笔能
运营自己录的，财务还没核实能
运营自己录的，财务已核实不能，按钮置灰，找财务
运营别人录的不能，按钮置灰，找财务

怎么操作

  1. 打开订单详情，往下到「收款」区，每笔收款右边有「撤销」按钮。
  2. 能撤的按钮是亮的，点了填原因（至少 4 个字）确认即可；钱退回未认款，订单已收金额同步减少。
  3. 不能撤的按钮是灰的，鼠标放上去会写明原因（「财务已核实」或「只能撤销自己录入的收款」），直接找财务处理。

运营看别人录的那笔：撤销按钮置灰，鼠标放上去写着该找谁

「跨单转移」按钮现在只有财务岗能看到（以前运营点了也是报错），「收款对账台」里的「核实」按钮非财务岗也是灰的。认款本身（人工确认 / 批量到账）没变，运营照常做。
认款流水（从收款对账台认上去的钱）不走这个撤销，仍要到收款对账台里「撤销认款」，那样钱才会退回挂账池。

三、批量创单「自动 +100」是怎么回事，以及报价表填 0 的含义

反馈说：批量创单保存后结算价会自动 +100。查下来：不是系统自己加，是结算价日历（机票报价表）在起作用——代理的纯机票单留空结算价时，系统按报价表里「航班号 × 出发日」那一格取同业价，再和系统价做差额记一行「代理结算价」。那单报价表填的是 900，系统价 800，就显示 +100；同一天系统价 1000 的单就显示 −100，代理实付都是 900。

不想按报价表走怎么办

  1. 批量创单页选好航班和班次后，「结算价/人」输入框下面会写「日历价 ¥X/人，留空 = 代理单按日历自动取价」——这就是提前告诉你会按多少收。
  2. 想按别的价：直接在「结算价/人」（整批）或名单里那个人的「结算价/人」填上，填了就不走报价表。
  3. 报价表本身不对：到「结算价日历 → 机票」里改那一格。

结算价日历 → 机票：按航班号 × 出发日维护每人同业价

报价表里填 0 ＝ 这一格没维护，不是「结算价 0 元」。以前把某天改成 0 会让系统按 0 元取价、把代理单打成 0 元单，现在已经改成：0 视同没填，代理单回落到系统动态价（套餐日历同理，会提示「结算价未维护」）。不想让某天走报价表就填 0 或删掉那一格都可以。
