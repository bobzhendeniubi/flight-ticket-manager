反馈表（9）五项新功能 操作说明

多人单单独改期 · 名单表签证状态按人 · 代理议价申请 · 改单去程/单回程 · 备注保存　·　2026-09-01

这次反馈表里的 5 条都做了，下面按条说怎么用。每条先说一句「解决了什么」，再给操作步骤和截图。
  1. 多人单只给其中几个人改期
  2. 全岗总表 / 全岗可用：签证状态一人一个
  3. 代理自助改结算价与议价申请
  4. 往返 / 套餐改成单去程或单回程
  5. 备注和签证状态的保存

一、多人单只给其中几个人改期

解决了什么：三人一张单，以前改期只能整单一起改。现在改期弹窗里能勾人，勾几个改几个。

怎么操作

  1. 打开订单详情，找到机票那一行，点「改期」（套餐单要先点开「金额明细」）。
  2. 弹窗最上面是改期乘客，默认全选。全选着不动就是整单改期，跟以前一样。
  3. 只想改某几个人，把不改的人取消勾选。
  4. 下面照旧选航班、班次、舱位、差价，点「确认改期」。

改期弹窗最上面多了乘客勾选，默认全选

只勾一个人：这个人会被拆成一张新单再改期

只勾部分人时系统做了什么

勾的人自动拆成一张新订单，新单号当场弹出，列表里能看到
新单按你选的班次改期，改期差价记在新单上
原单剩下的人不动，班次不变
钱已收款按人头份额跟着人走，两张单各自对得上
已付清的单也能这样拆了（以前付清的单不让拆）
已出票的单也能拆；拆出去的人改期后原票作废，需票务台重开
住宿拼房按半间劈——没来的人带走半间和自己那份钱，两张单同酒店同房型同日期，房控页按 1 间计；单住的按整间跟着人走
升舱升舱位数跟着拆走的人数填，两张单各自对得上
有酒店分房的单：同一个房组可以一半走一半留——手工拆单弹窗勾选「自动劈房组」就会按半间/整间自动分；no-show 处理、按人改期这两处会自动劈，不用你手动分房。结算价锁定 / 收款复核锁定不再拦拆单，改成两张单各自锁上。佣金已计提但还没申请结算的，按份额自动分到两张单；已经进入结算流程的佣金拆不了，要先找财务处理完。有进行中退款、有待确认的改档申请，或者本单有多条套餐行的，仍然拆不了，提示会写清楚原因。
已出票的单也能这样改。票跟着人走：拆出去的人连同 PNR / 票号一起到新单，改期后他原来那张票作废，票务台要在新单上重开；留在原单的人票不动。勾人时面板会有一条提醒。
万一拆成了但改期没成功（比如新班次刚好卖完），红字会告诉你新单号，到新单上重新改期就行，拆单不会退回去。

手工拆单弹窗长什么样（套餐单也能拆）

订单详情底部「运营工具」里的「拆单（拆出部分乘客）」是同一套逻辑的手工入口。勾人之后，弹窗会当场算出新单应收、随拆转移的已收款，套餐住宿行还会给一个建议间数（两个人拼一间、拆走一个人，就建议 0.5 间）；有升舱的单下面还会多一块「随拆走的升舱人数」。留空＝按人头自动分，填 0＝该行全留在原单。

套餐单拆单弹窗：勾人后给出新单应收、随拆已收款，套餐住宿行带「套餐住宿」标和建议间数

点「下一步」后的确认页：拆出乘客与份额、新单应收合计、住宿 / 升舱怎么搬、佣金要不要处理，一次核对清楚——确认后不可撤销

二、全岗总表 / 全岗可用：签证状态一人一个

解决了什么：同一张单里自备签的客人，导出来以前也写「需要」；一个人送签了，全员都亮「已送签」。现在一人一个状态，复查的同事能直接看。

操作没变，还是订单管理页上方的「导出全岗总表」和《全岗可用》导出。

导出入口没变

导出后「签证状态」列的样子（示意）

这位客人的情况导出来写什么
自备签自备签
签证台已送签已送签
签证台材料准备中材料准备
还没动跟整单一样：需要 / 电子签
整单选了「不需要」或「已签证」全员写整单的值，不看个人
《签证专用》那张表本来就不含自备签的人，没有变化。

三、代理自助改结算价与议价申请

解决了什么：报价表更新快，代理录单时系统按协议价算出来的结算价常常已经过时。现在代理对自己名下的单，在结算价锁定前可以自己填、自己改，改完立即生效，不用等运营确认。锁定后再改才走「议价申请」。

代理自己改的价会进审计，动作名是「代理自助改结算价」。第二天核对结算价时，审计流水里能一眼看到哪些单代理动过。核对完锁了结算价，代理就改不了了。

代理那边：录单时直接填，下单后在详情改

  1. 代理录单时，弹窗里有一块「结算价（可自填）」：整单填一个结算总价，或者两人以上按人填。不填按协议价自动算。
  2. 下单后想改，打开订单详情，找「结算价」那块，填新的结算总价点「立即生效」，订单金额当场按差额调整。
  3. 三种情况系统会拦，提示联系运营：订单已进结算单；订单已开票；订单已收款，改后金额低于已收金额。
  4. 结算价已锁定的单，同一个地方会变回「提交议价申请」，运营确认后才生效。

运营这边：两个地方能处理

订单列表上方有「议价申请」按钮，橙色数字是待处理的条数。点开是队列，每行能直接确认或驳回，点单号可以打开那张单。

列表上方的入口，带待处理数

待处理队列：申请价、当前应收、差额一目了然

订单详情里也有一块「议价申请」，黄色卡片就是待处理的。

订单详情里的议价申请卡片

点什么发生什么
确认按「申请价 − 当前应收」生成一条调价，订单应收变成申请价。差额为正是补收，为负是优惠。
驳回申请标为已驳回，可写原因，代理在订单详情里能看到。
确认时用的是当时的应收，不是申请那一刻的。中间加过改期费、补过房差，这些不会被抹掉。一张单同时只能有一条待处理申请。

四、往返 / 套餐改成单去程或单回程

解决了什么：客人只飞一段，以前没法把不要的那一段放回去卖。现在订单详情里每一段旁边都有取消按钮，取消后座位当场放回库存，订单变单程。

先分清楚是哪一种情况：客人没登机（航司 no-show 名单）走「no-show 处理」，钱和成本一分不动，回程座位可以先放出去卖、代理来要还能恢复——不是本节说的这个功能。客人是自己决定不飞、要按退改政策退钱的，才用本节的「取消航段」。两者怎么选、区别在哪，见本节末尾对照表。当时标 no-show 没勾「同时释放回程」的单也不用担心漏放：订单详情同一个入口会一直留着，只是文案变成「释放回程座位」，之后随时能点它把回程放出去，不用重新勾人。

怎么操作

  1. 打开订单详情（套餐单先点开「金额明细」）。
  2. 去程那行旁边是「取消去程（改单回程）」，回程那行旁边是「取消回程（改单去程）」，点你要取消的那一段。
  3. 面板打开会先预检：不合格的会逐条写原因，合格的显示这段的金额、按取消政策算出的手续费、本单应收会从多少降到多少。
  4. 手续费默认按取消政策；要手动填的话选「手动填写」，金额不能超过这段的价，并且必须写原因。
  5. 这段如果已经出票，面板会琥珀色提示「有 N 条确认出票记录」，要勾选「已知悉」才能继续——勾了之后系统会自动给票务派一条「撤名单/退票」工单。
  6. 点「确认取消」，再确认一次就生效。

去程 / 回程两行各自的取消按钮

预检面板：这一段的金额、手续费、应收降幅

确认之后

代理单取消一段之后应收下降，佣金不会自动重算，需要财务手工冲销。

取消航段 vs. no-show 释放：怎么选

取消航段（本节）no-show 释放（订单详情「no-show 处理」）
适用场景客人主动不飞，要按退改政策退钱客人没登机（航司 no-show 名单）
钱应收下降，按政策扣手续费一分不动，不退不扣
能否恢复不能，座位放出去就抢不回来能，代理来要就「恢复回程」，有余位直接占，没余位走超售确认
算不算飞行次数——（该段本就取消了）去程不计飞行次数（客人没坐这趟）
已出票怎么办可以取消，勾「已知悉」后系统自动派撤名单/退票工单给票务回程座位释放时若已出票，同样自动派撤名单/退票工单；去程本身不涉及退票

五、备注和签证状态的保存

解决了什么：改完备注往下翻找不到保存按钮。其实按钮一直在备注块正下方，只是以前改了字才出现。现在它一直在。

没改动时按钮是灰的，旁边写着「改动需点保存才生效」

改了字按钮就亮起来，点一下保存

签证状态那个下拉也是靠这个按钮保存的。乘客旁边的「改自备签 / 改回随团」是点了当场生效，不用再保存。
