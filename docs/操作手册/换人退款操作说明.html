换人退款 操作说明

客人临时去不了、位子转让给别人时怎么在系统里走　·　2026-09-01

一句话：原来那张单扣一笔换人费，剩下的钱退给原来那位客人（财务核账时打款）， 接手的新客人另开一张单按当天价正常收。两张单在钱上完全分开。

一、什么时候用这个

客人下了单也付了钱，临时告诉你去不了，让你帮忙把位子代卖出去。找到接手的人之后，他按当天的价另开一张全新的单。

公司对原来那位客人收一笔换人费，剩下的钱退给他。比如他当初交了一千，换人费扣四百五，就退五百五给他。

两张单是分开的。新客人那张单该收多少收多少，跟原单没有任何转账关系。原单退的钱是真的退给原客人，不是顶到新单上。
如果只是同一个价、同一个代理，单纯把某位乘客换成另一个人，那不用走这条路——订单详情里每位乘客旁边的换人 / 编辑就够了，位子不动、单子也不关。

二、怎么操作

第一步　打开原来那张单，找到付款那块

订单详情里往下拉到付款情况，已付 / 应收那张卡片下面就是换人退款。

付款卡片里的换人退款入口

按钮点不动的话，鼠标停上去会告诉你为什么，一般是这单已经取消或退过款了、这单没收到过钱、或者详情还没加载完。

第二步　填三样东西

刚打开的样子

填什么说明
换人费这次扣多少，直接填数字。每单可以不一样，不收就填 0。
接手订单号选填。新客人那张单的单号，只作记录用。新单还没录可以先空着，之后在订单详情里再补。
原因写清楚怎么回事，这句话会留在单子备注里，以后谁来查都看得到。

第三步　看清楚数字再提交

填的时候它会当场把账算给你看：这单净收多少、扣掉多少换人费、最后退给客人多少。

净收一千、换人费四百五，退给客人五百五

数字对了再点提交，还会再问你一次。

三、提交之后会怎样

原单状态退款申请中
原单座位当场放出来
钱什么时候到客人手上等财务核账批准后打款，不是立刻
公司留下的¥450，就是那笔换人费
新客人那张单不受影响，照常收款
这单的代理佣金会全部冲掉。换人费这笔钱不算佣金。
提交之后座位就放出去了。要撤只能走退款驳回，客人的位子不一定还抢得回来，所以提交前把三行数字看清楚。

财务这边注意

退款那张卡片改过了。以前上面显示的金额是按退改规则当场算的，跟实际该打的钱可能对不上；现在直接显示这笔退款申请冻结的金额，那个才是该打的数，照着打就行。换人退款还会单独标出「换人费（不退）／应退」两行。

四、填不进去的几种情况

情况怎么办
换人费填得比净收款还多不能超过这单实际收到的钱，改小一点。
这单没收到过钱没钱可退，直接取消就行。
这单已经有一笔退款申请挂着先把那笔处理完。
接手订单号填了但查无此单核对一下单号，或者先留空、等新单录好再补。
接手订单号填成本单自己填新客人那张单的号。

换人费填得跟净收款一样多是允许的，意思是全扣、一分不退，界面会明确显示退给客人 ¥0。

换人费吃满全款，退给客人显示 ¥0

五、以后怎么查

换人退的单跟客人自己要退的单，现在在系统里分得开：

  1. 订单列表里，换人退的单在状态旁边有一个换人小标签，鼠标停上去能看到换人费和接手单号。
  2. 订单 CSV 和财务那两张表都多了三列：退款类型（换人退款 / 普通退款）、换人费、接手订单号。
  3. 想统计一个月换了几个人、一共收了多少换人费，按退款类型筛一下就出来了。
几张名单表（全岗总表、票务、签证、进单统计）不受影响——那些表本来就不含已退款的单。

被换掉的那位客人一直留在系统里，原单没有删，随时查得到。
