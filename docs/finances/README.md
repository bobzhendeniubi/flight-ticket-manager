## 更新规则

**每月底**：

1. 打开 `支出明细` Tab，在「═══ 合计 ═══」**上方** 加新月份的 section + 几条流水
2. 已花成本 Tab 的公式会自动滚动
3. 重算公式：`python3 ~/.claude/skills/xlsx/scripts/recalc.py docs/finances/COSTS.xlsx`

**字段规范**（明细 Tab）：

| 列 | 内容 | 例子 |
|---|---|---|
| 日期 | YYYY-MM-DD | 2026-05-20 |
| 类别 | 必须是 8 大类之一（开发外包 / Claude Code / OpenAI / 服务器 / 域名 / GitHub / 设计 / 杂项） | 开发外包 |
| 供应商 / 项目 | 一句话 | Phase 2 反馈 wave 1 |
| 金额 (USD) | 蓝色数字 = 假设/估算 | 900 |
| 具体买了什么 | 一两句话讲清楚 | PNR Excel / 护照 zip / 待办系统 |
| 工时备注 | 开发外包用 ~Xh | ~55h |

**颜色规范**：
- 蓝色文字 = 硬编码输入值
- 黑色文字 = 公式 / 自动计算
- 黄色底 = 合计 / 关键单元格
