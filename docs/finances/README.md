## 更新规则

**每月底**：

1. 打开 `支出明细` Tab，在「═══ 合计 ═══」section header **上方** 加新月份的 section + 几条流水
2. 已花成本 Tab 的公式会自动滚动（SUMIF + 合计单元格直接引用明细累计行）
3. 重算公式：`python3 ~/.claude/skills/xlsx/scripts/recalc.py docs/finances/COSTS.xlsx`

**字段规范**（明细 Tab）：

| 列 | 内容 | 例子 |
|---|---|---|
| 日期 | YYYY-MM-DD | 2026-05-20 |
| 类别 | 9 大类之一（开发者 / AI 编码工具 / 服务器 / 域名 / GitHub / OpenAI / 杂项 / 设计 / 预留 buffer / OpenRouter） | 开发者 |
| 供应商 / 项目 | 一句话 | Cursor Pro |
| 金额 (USD) | 蓝色数字 = 假设/估算；不要写公式 | 750 |
| 具体买了什么 | 一两句话讲清楚 | PNR Excel / 护照 zip / 待办系统 |
| 工时备注 | 开发者类别用，~Xh | ~60h |

**颜色规范**（xlsx skill 标准）：
- 蓝色文字 = 硬编码输入值（可改）
- 黑色文字 = 公式 / 自动计算
- 黄色底 = 合计 / 关键单元格
