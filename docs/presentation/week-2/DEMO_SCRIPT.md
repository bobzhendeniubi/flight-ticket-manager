## 第一段 · 客户视角（10 分钟）

### Step 1 · 首页 + 搜机票（不登录）

- 打开 http://47.83.249.163/
- 介绍：「澳门直飞岘港，自营航班，每天 1 班」
- 顶部 nav 五大块：机票 / 酒店 / 接送 / 签证 / 套餐
- 搜索：MFM → DAD，下周四
- 点结果中价格最高的那条 → 商务舱卡片
- **重点演示**：动态价格 + 限时优惠标识
- 加购物车 → 进结账

### Step 2 · 登入 customer 完成下单

- 退出，登入 `customer@ftm.local` / `Password123!`
- 进结账页：填联系信息 + 乘客信息
- **重点演示**：乘客数 = 票数（少了系统会拦）
- 点支付 → 沙盒成功
- 进"我的订单"看新订单

### Step 3 · AI 助手下单

- 退到首页，点右下角浮窗 🤖
- 输入：「明天 2 个人去岘港，要往返」
- AI 给方案 → 点"OK·看详情" → "确认下单"
- 进结账页（AI 已经把信息填好）

> 演示要点：「客户不会自己想去打开 5 个页面比价；AI 一句话就帮他搞定。」

## 第二段 · 代理视角（10 分钟）

### Step 4 · 一级代理看团队

- 退出，登入 `agent1@ftm.local`
- nav 多了「我的团队」和「我的分成」（**重点：刚加的**）
- 进「我的团队」
- 看到二级 + 三级的层级结构
- 试着新建一个二级代理（填邮箱 + 手机 + 名字）

### Step 5 · 一级代理看分成（核心新功能）

- 进「我的分成」
- **指着 4 个 KPI 卡讲**：我的应得 / 下级累计 / 待打款 / 结算单总数
- 切换"范围"过滤 → 仅自己 / 仅下级 / 全部
- 点开任意一行结算单 → 右侧抽屉
- 抽屉里讲：销售额 / 应得佣金 / 分给下级 / 应付（含预付抵扣）
- 滚到底部看「佣金明细」表（按订单 + 产品类型）

> 演示要点：
> - 一级代理能看到所有下级的分成（透明）
> - 自己那行有「我自己」蓝徽章标识
> - 金额都是 ¥ 格式，不是裸数字
> - 状态机：草稿 → 待审批 → 已核准 → 已支付

### Step 6 · 切到二级代理对比

- 退出，登入 `agent2@ftm.local`
- 进「我的分成」
- **重点**：只能看到自己 + 三级，看不到一级
- → 这就是层级 RBAC

## 第三段 · 管理员视角（15 分钟）

### Step 7 · 后台登入

- 打开 http://47.83.249.163:8080/
- 登入 `admin@ftm.local` / `Password123!`
- 左侧 nav 一圈：订单 / 代理 / 客户 / 出行人 / 定价 / 结算 / 履约 / 审计 / …

### Step 8 · 订单管理 + 批量改状态（核心新功能）

- 进「订单管理」
- 看到 6 条 DEMO-* 订单 + 客户/代理刚下的真单
- **重点演示批量**：
  1. 勾选 3 单
  2. 顶部出现工具条：「已选 3 条 ｜ 改为 [下拉] [强制] [应用] [清除]」
  3. 选「已支付」 → 应用
  4. 看 3 单状态都变了
- **重点演示行内单改**：
  1. 找一条订单，右侧"操作"列
  2. 点「改状态…」下拉 → 选目标状态
  3. 弹确认框 → 确认 → 状态变了

> 演示要点：
> - 默认"强制模式"，可绕过状态机（管理员特权）
> - 关掉强制模式则按标准流转
> - 批量出错时会显示失败明细

### Step 9 · 审计日志可读化（新功能）

- 进「审计日志」
- **对比讲**：「以前这页都是 `BATCH_FORCE_ORDER_STATUS` 这种代码 + 一坨 JSON，没法看。现在：」
- 表格"动作"列：emoji + 中文（小灰字保留原始代码）
- "变更摘要"列：「目标状态: 待支付 → 已支付」一句话
- 点任意一行 → 抽屉
- 抽屉"变更"区：彩色 diff（−红 +绿）
- 底部"查看原始 JSON"折叠区可展开（给开发排障用）

> 演示要点：
> - 三档严重度：关键 🔴 / 警告 🟡 / 一般 ⚪
> - 强制改状态、退款都标 WARNING；支付成功标 CRITICAL
> - 这是合规和纠纷追责的基础

### Step 10 · 其他后台模块（快速过）

- 代理：层级结构 + 预付余额管理
- 结算：月度结算单 + 状态流转
- 定价：日期等级 + 余位阶梯（动态价引擎）
- 履约：自动出票任务队列

## 演示中可能被问到的问题

| 问题 | 怎么答 |
|------|--------|
| 价格能不能自动算优惠？ | 可以，已有日期等级 + 余位阶梯两层动态定价 |
| 代理佣金率能改吗？ | 后台「定价」模块可以按代理+产品类型设佣金率 |
| 客户能自己注册吗？ | **不行**。注册由代理后台开通（防黄牛） |
| 出票是真的吗？ | 当前沙盒；接航司接口在 milestone 3 |
| 数据安全吗？ | 备份每日跑；后续接 Cloudflare WAF |
| 移动端怎么样？ | 已适配，可在 nav 点「移动预览」实时看 |
| 多语言支持哪些？ | 中/英/越，右上角切换 |
| 上线时间？ | 公测 1-2 周后；正式上线视测试结果 |
