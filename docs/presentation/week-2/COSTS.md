## 3. AI 成本拆解（这块是重头戏）

**AI cost 主要是 token**：每次对话按输入 + 输出 token 计费。
按 Claude Sonnet 4.6 当前定价：**输入 $3 / 1M tokens，输出 $15 / 1M tokens**

```
单次对话（5 个轮次平均）
  输入 tokens: ~10,000  → $0.030
  输出 tokens: ~2,500   → $0.0375
  小计：             ~$0.067 / 对话

启用 prompt caching 后（缓存 system prompt + tool 定义）：
  缓存输入 tokens: ~9,000 × $0.30 / 1M = $0.0027
  全价输入 tokens: ~1,000 × $3 / 1M    = $0.003
  输出 tokens: 2,500   = $0.0375
  小计：             ~$0.043 / 对话（省 ~36%）

实际经验值（已优化）：~$0.013 ~ $0.05 / 对话，视复杂度
```

**意思就是**：1000 个客户聊一次 AI ≈ $13 ~ $50。

### AI 成本优化杠杆

| 杠杆 | 状态 | 节省幅度 |
|------|------|---------|
| Prompt caching（系统 prompt 缓存） | ✅ 已做 | ~30-40% |
| 选模型分级（简单查询用 Haiku） | ⏳ 待做 | ~50% |
| 客户端 OCR（Tesseract，不调 API） | ✅ 已做 | 100%（OCR 这块） |
| 短期对话历史窗口（不无限拼） | ✅ 已做 | ~20% |
| 高频问题答案缓存（FAQ 不每次问 AI） | ⏳ 待做 | ~15% |
| 业务时间外限频 | ⏳ 待做 | ~10% |
| Batch API（异步报表 / 导出） | ⏳ 待做 | 50%（仅异步路径） |

## 4. 服务器费用拆解

### 当前（staging）
- **阿里云 HK 轻量服务器** 4C8G + 100GB SSD + 5Mbps 带宽
- $32/月（包月，月初付）
- 跑：sales-web nginx + admin-web nginx + Node.js backend + Postgres + Redis + worker（全部 Docker Compose 在一台机）

### 公测期方案
- 同一台 4C8G **够用**（公测客户 ~500，并发不高）
- 加一台 ~$15/月小机做 Postgres 异地备份
- → ~$50/月

### 稳定期方案
- **应用层**：升到 8C16G ~$80/月，或者拆 2 台 4C8G 做主备 ~$64/月
- **数据库**：独立 RDS PostgreSQL（阿里云 RDS 4G 内存 ~$50/月）
- **Redis**：托管 Redis 2G ~$20/月
- **Worker**：另一台 2C4G ~$20/月（跑 BullMQ 队列、自动出票、定时任务）
- → ~$200-300/月

## 5. CDN 费用拆解

### 当前
- **Cloudflare 免费层**：DNS + 基础 DDoS + 全球 CDN，$0/月

### 公测期
- 流量小（~500 客户），免费层够用
- 想加 WAF 规则（防爬虫、防黄牛刷 AI 助手）→ **Cloudflare Pro $20/月**
- 加图片优化（自动 WebP/AVIF）→ Polish 包含在 Pro 里

### 稳定期
- 视流量决定：
  - 流量 < 1TB/月 → Cloudflare Pro $20
  - 流量 1-10TB/月 → Cloudflare Business $200
  - 静态资源大量 → 加 Cloudflare R2 存储（$0.015/GB · 月）
- 中国大陆访客：考虑加阿里云 CDN 国内节点（按量计费 ~$0.05/GB）

## 7. 单位经济学（成本 vs 收入）

### 公测期（保守估）
- 月单量：100 单
- 平均客单价：¥3,500
- 月 GMV：¥350,000 ≈ $48,000
- 平台抽成（8%）：¥28,000 ≈ **$3,900 月毛利**
- 月成本（~$1,000） vs 月毛利（$3,900） → **覆盖 4×**

### 稳定期
- 月单量：1,000 单
- 月 GMV：¥3,800,000 ≈ $530,000
- 平台抽成：¥304,000 ≈ **$42,000 月毛利**
- 月成本（~$5,000） vs 月毛利（$42,000） → **覆盖 8×**

> 单位经济学健康。**关键不是成本控住，是订单量做起来。**
