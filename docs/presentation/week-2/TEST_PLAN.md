## 2. P0 测试场景（必须跑通）

### 2.1 客户从搜机票到付款全链路

**账号**：`customer@ftm.local` / `Password123!`

1. 打开 http://47.83.249.163/
2. 首页搜索：澳门(MFM) → 岘港(DAD)，选未来 7 天某天
3. 点击搜索结果中的"立即预订"
4. 加入购物车，进入结账
5. 填写联系信息 + 乘客信息（人数 = 票数）
6. 点"立即支付"，看是否进入沙盒支付页 → 模拟成功
7. 进入"我的订单"，看是否出现刚下的订单，状态是"已支付"

✅ **验收标准**：
- 每一步页面无报错
- 下单后订单立即出现在"我的订单"
- 切换中/英/越，所有按钮和标题都翻译过来

---

### 2.2 AI 助手下单

**账号**：`customer@ftm.local`

1. 进入首页，右下角点 AI 助手浮窗
2. 输入：「明天 2 个人去岘港，要往返票」
3. 看 AI 是否给出航班建议 + 价格
4. 点"OK · 看详情" 看明细
5. 点"确认下单" → 应跳到结账页

✅ **验收标准**：
- AI 推理时间 < 5 秒（不算等待）
- 推荐结果与航班搜索一致
- 加购后购物车数量 +1

---

### 2.3 代理看自己的分成（新功能）

**账号**：`agent1@ftm.local` / `Password123!`

1. 登入前台（http://47.83.249.163/）
2. 顶部 nav 应该看到「我的团队」+「我的分成」两个链接
3. 点「我的分成」
4. 应该看到 4 张 KPI 卡 + 过滤区 + 结算单表格
5. 切换"范围"过滤（自己 / 仅下级 / 自己+下级），数据应该跟着变
6. 点表格里某条结算单 → 右侧抽屉打开看明细

✅ **验收标准**：
- 一级代理能看到自己 + 二级 + 三级的结算单
- 二级登入只能看到自己 + 三级
- 三级登入只能看到自己
- "我自己"那一行有蓝色徽章标识
- 金额数字显示成「¥1,234.56」格式（不是裸数字）

---

### 2.4 后台批量改订单状态（新功能）

**账号**：`admin@ftm.local`（在后台 :8080 登）

1. 进「订单管理」
2. 列表上每行有勾选框，表头有全选框
3. 勾选 2-3 单 → 顶部出现批量操作工具条
4. 选目标状态（比如"已支付"），点"应用"
5. 看是否所有勾选订单状态都改了

✅ **验收标准**：
- 全选 + 反选 + 取消选都正确
- 默认开"强制模式"，可绕过状态机校验
- 关掉强制模式时，不允许的状态流转会失败并显示错误明细
- 单条订单"操作"列也有「改状态…」下拉，可以快速改单条

---

### 2.5 后台审计日志可读化（新功能）

**账号**：`admin@ftm.local`

1. 进「审计日志」
2. 应该看到一堆人类可读的中文动作（不是 `BATCH_FORCE_ORDER_STATUS` 这种代码）
3. "变更摘要"列应该是「目标状态: 待支付 → 已支付」这类一句话
4. 点任意一条 → 右侧抽屉打开
5. 抽屉里"变更"区是分行的彩色 diff（−红 / +绿）
6. 抽屉底部有"查看原始 JSON"折叠区，可以看后台原始数据

✅ **验收标准**：
- 表格里看不到全大写动作代码（小灰字除外）
- 金额自动加 ¥
- OrderStatus 等枚举显示中文
- 原始 JSON 折叠区能展开

## 3. P1 测试场景

### 3.1 代理创建下级

**账号**：`agent1@ftm.local`

1. 进「我的团队」
2. 应该看到一级代理只能创建二级，依此类推
3. 试着创建一个新二级代理：填邮箱 + 手机 + 名字
4. 创建后告诉 Bob 看新代理是否能登入

### 3.2 取消订单 → 退款流程

1. 用 customer 下一个新单（不要用 DEMO-* 那些）
2. 走完结账，状态变"已支付"
3. 进"我的订单"，点取消 → 看退款报价 → 确认
4. 订单状态变"退款申请中"
5. 用 admin 进后台，找到这单 → 同意退款
6. 客户端订单状态变"已退款"

### 3.3 后台代理管理

**账号**：`admin@ftm.local`

1. 看代理列表 → 看层级结构
2. 调整某个代理的预付余额
3. 走结算单生成流程（如果有数据），看金额是否合理

## 5. 已知不测的部分

- ❌ **真实支付**：当前是沙盒模式，不会扣钱。看到"支付成功"是模拟。
- ❌ **真实出票**：后台点"出票完成"只是改状态，不会调真航司接口。
- ❌ **小程序**：还没部署，本次测试不涉及。
- ❌ **HTTPS**：IP 直连还没证书，浏览器会显示"不安全"，正常。
- ❌ **OCR / 护照识别**：客户端有功能但识别率约 60-75%，不必特意测准确率。
