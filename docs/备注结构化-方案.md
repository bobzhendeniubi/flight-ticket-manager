# 备注结构化：把高频备注做成字段（2026-09-17）

## 背景

实测 14 天 2470 单里 2455 单写了自由备注，四个专用备注栏合计只用了 21 次。备注里高频出现、且下游（分房、房控、票务）
要靠人眼看的信息：

| 备注词 | 14 天单数 | 现状 |
|---|---|---|
| 大床 / 双床 | 668 | `Passenger.bedPref` 字段早就有，但录单界面没露出，全库乘客全空 |
| 单住 / 拼住 | 555 | `Passenger.singleRoom` 已在用（写了备注的单里七成同时勾了字段），备注是习惯性重复，**不动** |
| 自备签 | 1093 | `Passenger.visaExempt` 已在用；OTA 名单解析器不认这个词，批量建单要手勾 |
| 单独编码 | 251 | 只来自 OTA 名单粘贴；解析器已识别出这个词但只塞进乘客备注，票务靠看备注判断是否单独出票 |
| 和某某同一个酒店 | 30 | 无字段；房控落位、分房表全靠看备注 |
| 满五次兑换（单程/往返）商务舱 | 82 | 无字段；票务靠看备注决定哪一程升舱、用谁的次数 |

运营/票务已确认（2026-09-17）：做成勾选项会填。

## 字段契约（前后端按此对齐，名字不再改）

### 乘客级 `Passenger`

| 字段 | 类型 | 含义 | 新/旧 |
|---|---|---|---|
| `bedPref` | `'DOUBLE' \| 'TWIN' \| null`（schema 仍接受 SINGLE/SHARE_OK 兼容） | 床型：大床 / 双床 / 不限 | 旧字段，新露出 |
| `upgradeRedeemLeg` | enum `UpgradeRedeemLeg { NONE, OUTBOUND, RETURN, BOTH }` @default(NONE) | 兑换升舱：用常旅客次数换商务舱的航段 | 新 |
| `upgradeRedeemNote` | `String?`（≤80） | 兑换说明，如「用某某的次数」「经济舱第一排」 | 新 |

### 订单级 `Order`

| 字段 | 类型 | 含义 | 新/旧 |
|---|---|---|---|
| `separatePnr` | `Boolean @default(false)` | 单独编码出票（本单乘客单独编码，不与他单合并 PNR） | 新 |
| `sameHotelWith` | `String?`（≤120） | 同酒店安排：要和谁 / 哪张单住同一家酒店（人名或单号，自由文本） | 新 |

`sameHotelWith` 做文本不做关联：备注里写的多是人名（对方可能还没录单），房控按名搜即可。

## 落点（缺一处都算没做完）

**录单（SingleOrderModal）**
- 乘客卡片：有酒店/套餐行时露出「床型」下拉（不限 / 大床 / 双床）；有机票行时露出「兑换升舱」下拉（不 / 去程 / 回程 / 往返）+ 说明小输入框。
- 订单级：「单独编码出票」勾选（有机票行时）；「同酒店安排」输入框（有酒店/套餐行时），放在备注区。

**批量建单（BatchCreateModal + parseOtaRoster）**
- 解析器新增识别并回填：`大床`→bedPref DOUBLE、`双床`→TWIN、`单住`→singleRoom、`自备签/自备签证`→visaExempt、`单独编码`→订单级 separatePnr（原来塞进乘客 note 的行为保留）。识别到的项写进 warnings 提示「已按名单勾选，请核对」。
- 表格加列：床型、兑换升舱（下拉）；表头区加「单独编码出票」勾选与「同酒店安排」输入。

**订单详情 / 列表**
- 乘客卡片与列表乘客子行：床型、兑换升舱作 chip（与现有「单住」「自备签」并排）。
- 订单头部：「单独编码」「同酒店：xxx」chip。
- 可改：乘客纠错弹窗（correctPassenger）允许改 bedPref / upgradeRedeemLeg / upgradeRedeemNote；改备注弹窗（updateOrderNotes）允许改 separatePnr / sameHotelWith。审计 before/after 带上。

**导出**
- 分房表（export-room-allocation）：加「床型」「同酒店」两列，紧挨「酒店类型」。
- 票务模板（export-templates ticketing 与 full）：加「单独编码」「兑换升舱」两列（值：去程/回程/往返 + 说明）。
- 全岗总表（export-master）：加同样四列，放在备注列前。

**房控**
- 随机档缺口面板 / 换酒店弹窗里列到订单时带「同酒店：xxx」提示。

**代理端**：代理自助录单同样露出这些字段（都不影响定价，无审批）。

## 不做

- 不改任何定价：床型、兑换、同酒店都不进 quote。
- 不做 sameHotelWith 的订单关联与校验。
- 存量回填单独出脚本（dry-run 先跑给运营看），不在本批。

## 存量回填（另做，需拍板后跑）

`backend/scripts/backfill-structured-notes.ts --dry-run`：只处理出发日 ≥ 今天的单；备注含且仅含一种床型词时给全单乘客写 bedPref；
含「单独编码」写 separatePnr；含「同(一个)酒店」时截取该短语所在分句写 sameHotelWith。含歧义（多人不同床型）的只列出不改。
